雲端證照真的會帶領你走向夢想中的工作嗎? AWS 與 Azure 證照的解析

2023年2月4日·2 分鐘

雲端證照真的會帶領你走向夢想中的工作嗎? AWS 與 Azure 證照的解析 #

Photo by Markus Winkler on Unsplash

大家好我是 EC，擁有 6 張 AWS 證照以及 5 張 Azure 證照，今天想要來分享我對兩種證照體系的比較，最後則會分享我對雲端證照的看法。

以下的分享非常主觀，我先幫大家打一下預防針XD

先列一下我擁有的 11 張雲端證照 #

  • AWS Cloud Practitioner
  • AWS Solutions Architect Associate
  • AWS Developer Associate
  • AWS SysOps Administrator Associate
  • AWS Solutions Architect Professional
  • AWS Security Specialty
  • Microsoft Azure Fundamentals (AZ-900)
  • Microsoft Azure Administrator Associate (AZ-104)
  • Microsoft Solutions Architect Expert (AZ-305)
  • Microsoft Azure Security Engineer Associate (AZ-500)
  • Microsoft Azure Network Engineer Associate (AZ-700)

Learning Path 規劃 #

AWS 證照 (https://aws.amazon.com/certification/)

AWS 分級非常清晰，分別為 fundamental 一張、Associate 三張、Professional 兩張，以及 Specialty 六張。證照路線規劃明確，speciality 的 domains 也區分得非常清楚，不會有重疊的部分。

通過一個考試就等於獲得一個證照，簡單明瞭。

通常大部分的人會選擇從 Cloud Practitioner 或是 Solution Architect Associate 考起。我個人覺得考 Cloud Practitioner 對求職或是職涯的幫助完全不大，而且這個考試通常是非技術人員在考的XD

除非考試免費或是你的目標是盡可能蒐集更多 AWS 證照，或是你是非技術人員(sales、account executive、manager)，但公司又要求你要考基礎 AWS 證照，不然建議技術職的大家完全可以從 Solution Architect Associate，省時省力XD (Cloud Practitioner 在面試的加分程度基本上是近乎於零XD)

Azure 證照 (https://learn.microsoft.com/en-us/certifications/browse/)

Azure 證照則是完全相反，他們有超多 fundamental (例如 AI、Azure、Power Platform、Dymanic 365 等等)、超多 Assocaites、超多 professional 跟 specialty 證照。

我覺得規劃非常混亂，完整的學習路線我到現在也沒搞懂過XD

其實我覺得在同一個領域有各種等級的證照不是壞事，可以讓大家循序漸進的學習，壞在 Azure 的規劃太糟! 更別提有些證照等於一個考試，有些證照等於兩個考試，例如 Solution Architect Expert = AZ104 + AZ-305，AZ 305 的前身還是 AZ303 & AZ304，到底要有多亂?XD

而且有些考試的名稱跟最終證照的名稱還不一樣，例如 AZ-104的考試名稱是 Microsoft Azure Administrator，但考試通過後的證照名稱是 Microsoft Azure Administrator Associate。AZ-305 的考試名稱叫做 Designing Microsoft Azure Infrastructure Solutions，通過之後拿到的證照叫 Microsoft Solutions Architect Expert (如果你之前已經通過AZ-104的話，不然光考過305也沒用)。我真心不懂他們為什麼要把一件很簡單的事搞得這麼複雜 lol

除此之外，Azure 證照領域的區分細緻到很奇怪的地步，例如把 identity 分出來單純做一個證照 (通常 identity 會是security的一部分，而且是比重最高的部分)。甚至其中一個 Azure service AVD (Azure Virtual Desktop) 也可以自己獨立出來一個證照，我覺得完全就是莫名其妙XDD

如果可以的話，我也是建議跳過 AZ-900，直接考 AZ-104。但針對 Azure 證照 AZ-900 有一個小秘訣，如果你上微軟的網站報名免費的 virtual training day，上完課之後就可以直接獲得免費的考試 voucher 一張! AWS 完全就沒有這個優惠!

考試本身 #

AWS 考試模式非常一致，不管是基礎證照或進階證照都是考理論知識，只是scope 不同以及深度不同而已。題型基本上就是單選題或是多選題。相信從小到大不知道考過多少考試的台灣人應該很習慣這兩種題型XD

Azure 考試模式天差地遠，例如 AZ-104 超級重視實作細節，甚至到了我覺得過頭的地步(例如 Azure portal 介面上每一個步驟的順序)。我覺得背誦這些小細節毫無意義，實際操作時在看文件照著做不就好了嗎？XD 但 AZ-305 就超級重視整體 solution 架構跟每一個服務的核心概念，如果你抱持著考 AZ-104 的心態去準備考試，只專注在背誦操作細節，那可能會有機會失敗XD

Azure 的考試題型非常多元，這點其實我還滿喜歡的，除了單選題、多選題之外，還有配對題、順序題、是非題，算是從不同方向測試了考生的知識。不過其中 case study 的部分我覺得操作介面真是爛弊了XD 首先題目上會有好幾個 tabs，然後每一頁都是一個超長的段落，題目跟選項又在另一個section，看敘述跟題目跟選項時，需要不停地跳來跳去……我每次寫到這個題型都很崩潰! 不過這個考試題型其實最接近實際工作情形。因為在實際工作上我們就是必須要多方面收集客戶的相關資訊 (existing infrastructure, target architecture diagram, any compliance requirements, cost concerns, limitations etc)，再根據客戶的要求來提出解決方案。

學習資源 #

AWS的學習資源多出非常多，不管是各大線上學習網站 (A Cloud Guru, Pluralsight, Whizzlabs) 或是 YouTube 資源都是比較多，甚至有些比較小型的教育訓練網站只會提供 AWS 的訓練課程，根本沒有 Azure 相關訓練。

雲端證照真的有用嗎？ #

簡單來說，我其實覺得完全沒用XDDD

等等，先別急著打我，我一開始就說過這篇文章是我個人非常主觀的想法，既然你都看到這裡了，就讓我好好來解釋一下為什麼我會這麼想。

首先，如果你是一個資深富有經驗的 solution architect or cloud engineer，我根本不需要看你有什麼證照，我也不在乎，我只要跟你聊個 10–15 分鐘，我完全就知道你有沒有辦法提供我需要的 solution 跟建議。

如果你是一個沒有什麼業界經驗的人，那就算你擁有再多張雲端證照，你的知識通常還是停留在紙上談兵的理論階段。如果你是一個進階的學習者，那你可能會自己登入平台照著網路教學實際操作過一遍，這一點我覺得很棒，但是在自己的私人帳戶操作是非常簡單的，你不需要設定權限，也不需要設定 role based access，你也不會受到公司 organisation policy 的限制 (有時候你 debug 半天，後來發現你的設定根本沒問題，只是被你看不到的 organisation policy 限制住了)。

等你真正進入職場後，你會發現客戶會問你的問題基本上都是你在documeantation 上找不到的，而且你必須根據客戶的需求、以及他們的環境、預算、complilance 的限制下試圖找出最佳解，有時候甚至會因為這些限制，最後弄出一個四不像的架構方案 (這就是現實職場人生啊lol)

再來是從面試官的角度，如果你有一兩張基礎證照，我的想法是「不錯不錯，你感覺對雲端技術真的有興趣，而且願意自主學習」，但這個想法大概只會停留三秒。最終要錄取哪一位求職者，跟你是否擁有證照完全沒有關係，基本上還是以面試表現為主 (如果公司真的對證照有要求，等你被錄取之後再要求你考也不遲，這些雇主也通常會規定你必須要在一定時間內考取某些指定證照)。

如果你有非常多張雲端證照，有些面試官可能會因此對你有比較好的第一印象 (但同樣的，這絕對不是最後要決定錄取候選人 A 還是錄取候選人 B 的決定因素)。同時，我自己也遇過好幾個同事反倒會覺得求職者是不是只是為了考而考，肯定沒有真正學習到什麼，所以證照也不一定完全是加分XD 但在絕大部分情況下，通常來說也不會扣分就是了！

結語 #

最後，雖然我個人覺得雲端證照完全對於職場之路幫助不大 (唯一的助益可能是考過證照之後可以在 LinkedIn 上炫耀一天，會有很多人恭喜你XD)

但我覺得對於雲端服務有興趣，但又不知道從何學起的人來說，由證照入手會是我自己最推薦的方法。因為網路上有很多系統性的學習資源，比起你東學一點西學一點最後不知道自己在學什麼或自己需要學什麼，按照證照的學習規劃來學習還是一條直接且高效的路線XD

而且當你還是新鮮人或是剛入職場不久時，你的確是沒有很多過往的經驗來證明自己，這時候有些證照在身，至少證明了你對這個領域有興趣、願意花時間自我學習，而且有考到證照還是代表你對雲端服務有一些基本的了解！
