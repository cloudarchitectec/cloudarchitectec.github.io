零基礎轉職澳洲工程師: 2019.09.01 There is no way to escape!

零基礎轉職澳洲工程師: 2019.09.01 There is no way to escape! #

最近兩天上的課程都偏軟實力，而不是寫程式的硬實力，上週五我們學了怎麼用 git 和 GitHub，今天我們學了專案管理。

今天下午公布了我們的第二個作業，每個人要做一個 terminal app! 第一個作業比較像是一般的大學作業，就是上網研究一下，然後回答 essay questions，九月底才要交，但是也是近乎20題😅

難道永遠都做不完的作業與學習，就是這個 bootcamp 的特色嗎?XD

接下來週二到週四就是專做這個 terminal app，週五上午每個人要上台報告，週五晚上 11 點交程式碼……

我必須說，今天下午老師在講解作業時，是我人生最想放棄這個 bootcamp 的一刻XDDD 因為實在是太複雜了!!!!! 老師一邊講一邊問同學有沒有問題，我想方設法問了兩三個，但同學們幾乎是一片死寂，我知道他們內心一定超茫然的啦😆

這個為期三天的作業，我們首先必須要先想出來自己的 app 要做什麼，接下來光是作業的評分標準就有 16 項!!! 16 項耶，我的天!!!

更別提其中有 3 個我們居然完全沒教過? 而且沒教過的部分老師居然不是跟我們說可以略過不管，而是在短短 10 分鐘內帶過這些概念，然後說 「好啦，那我們現在就算教過了，你們可以開始動手了 (Alright, now you are good to go!)」 我當場真心台灣人問號!!!! 本來這個作業就已經夠讓人雲裡霧裡了好嗎???!!! 😱

然後老師稍微提醒了一下大家應該有的心態，說「在現實生活中本來就不是每一件事都有人先教你怎麼做，才讓你去做，學會如何自己查資料是成為工程師非常重要的一步! 所以大家千萬不要想說，這個東西又沒有教，現在憑什麼叫我在作業中做出來?」

前半部我認同，但中文有一句話叫做「不教而殺謂之虐」老師你知道嗎? (雖然他肯定不知道，因為他根本就美國人😆)，再加上我們只有三天要做這麼多事，居然還要出新東西然後讓我們自己花額外的時間去研究，不會太為難人嗎!!!!!!更別提我現在還有些前兩週的課堂練習做不出來!!! 😭😭😭

(未來的 EC: 後來我才發現這其實根本就是職場的常態哈哈哈！就是有很多連 規格跟使用者需求都還沒訂好，但上面就希望你開始動手做的任務XD)

當下真的覺得我好想回去之前的工作，不想轉職了啦!!! 但是現在我工作也辭了，bootcamp 退選日也過了，真心也是退無可退😭

順便在這裡整理一下這個 project 要做的事，讓你們知道到底有多雜又多難XDDD

如果你們覺得下面我整理的筆記就超煩的，那你知道我們光是作業說明就有2050字，然後評分標準又是另一個 3205 字的文件嗎? 再加上新概念加上模糊不清的指示，難怪大家今天下午聽到快發瘋😀🙉🙉🙉😲

Assignment breakdowns

  • Ideas/ features/ research
  • Coding/debugging (actual programming)
  • software development plan (in markdown)

o Statement of ‘Purpose’ and ‘Scope’ (300–500 words)

o Features (300 words, approx. 100 words per feature)

o User Interaction and Experience

  • Control Flow Diagram
  • Implementation Plan (screenshots from Trello)
  • Status Updates/Development Log (100–200 words)
  • Help file (100–200 words)
  • Test Application (outline of the testing procedure and cases)
  • Developer Operations (throughout the development of the application )

o source control — git: regular commits (at least 20), push all commit to GitHub

o project management platform — trello:

o script — developer tools to automate the building and testing of the application

  • Presentation (5 mins)

o prepare ppt slides (5p?)

o practice & timing

PS: 壓力大果然讓人想狂花錢，在外面吃完晚餐後，我還跑去星巴克點了一杯熱巧(最便宜的選項，最小杯加自帶杯子只要$4)準備重新讀一下作業規定再回家。沒想到裡面居然還有棉花糖跟鮮奶油，重點是莫名的好喝耶💗~~~

總之接下來幾天我可能會連睡覺的時間都沒有嗚嗚嗚嗚嗚😭💀💀
