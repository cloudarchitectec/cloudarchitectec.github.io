最近回顧了一下自己的學經歷，列著列著忽然有種「喔～原來我真的做了不少事情」的既視感（人生沒有白活啊XD）。

想說順便來跟大家分享一下，讓你們更加了解我的背景~

### **個人經歷**

  * 大學: 政治大學英文系 (荷蘭交換學生半年)
  * 台灣職場(一年): 翻譯公司 專案經理
  * 澳洲打工度假 (兩年): 旅館清潔、夜市小吃攤、麥當勞、餐廳服務生、蘋果農場包裝、超市生鮮區員工
  * 研究所(一年後休學): 台師大翻譯所
  * 澳洲留學(兩年半): 麥考瑞大學研究生文憑(翻譯)、維多利亞大學研究生文憑(會計)、澳洲國立大學研究生文憑(澳洲移民法)
  * 澳洲就業: 移民仲介顧問、會計職業評估員(三年)
  * 決定轉職 : 就讀程式訓練營 Full Stack Web Development Bootcamp (六個月)
  * 進入澳洲科技業:

    1. 2020.09–2022.10: Professional Service Cloud Architect at Amazon Web Services 亞馬遜雲服務科技顧問
    2. 2022.10–2023.08: Cloud Solution Architect at Microsoft 微軟雲端解決方案架構師 
    3. 2023.08 ~ now: DevOp & Platform Engineer at Shell

### **大學: 政治大學英文系**

高中成績優異，以全校文組第一名畢業的我，進了英文系之後覺得很痛苦XDD

雖然我喜歡文學，但我的英文能力其實普通。政大英文系的學生除了各大高中的高材生之外，還有很多歸國子女 (其中有些人英文完全比中文好，感覺超荒謬XD) 或是那種指考英文將近滿分靠著這點轉系進英文系的人。每次交文本分析作業的時候我都是在及格邊緣，口說課也是結巴到不行 (沒辦法，鄉下小孩加上我很內向～哭)，我記得第一學期我好像是班上倒數第五名，對於當時的我簡直是天崩地裂 (但現在想想其實根本沒什麼大不了的，反正有最後拿到大學文憑就好XD)。

其實我一直都滿嚮往國外生活的，所以後來就考了政大的交換學生，去荷蘭交換了半年。

第一次長期在國外生活其實很新鮮，我還記得第一次看到下雪的情景，還有在雪中騎腳踏車去上學，結果因為雪太滑而在街上摔倒的時候XDDD。荷蘭真的是一個風景如畫的國家，每一條街、每一條運河都像是一幅畫。當時也利用在歐洲的機會，去了八個國家：荷蘭、比利時、盧森堡、挪威、英國、愛爾蘭、法國、德國，覺得非常棒！

### **台灣職場: 翻譯公司的專案經理**

大四上學期出國交換半年後，回來只剩一個學期就畢業了。當時也沒想好自己之後要做什麼，所以我就想說找一個對未來比較有幫助的打工好了（之前大學打工都是在餐廳當服務生），於是我就成功進入了一家翻譯公司當工讀生。

畢業時也沒有太多計畫，於是就順勢加入翻譯公司當專案經理兼筆譯。當時的我還是很喜歡翻譯的，可是公司比起全職筆譯更需要的是全職 PM (project manager)，因為筆譯外包給譯者就可以了。

做了一年之後，對於職場感到倦怠，身邊的朋友說想要去考師大翻譯所，於是我也跟著去考了。沒想到在沒有準備的情況下考了筆譯所第三名XD

朋友因為沒考上而打算去紐西蘭打工度假，同時我還是不確定未來想做什麼，於是就想說那我先休學，先去澳洲打工度假回來再讀好了，這樣之後也比較容易跟職場銜接，於是我就出發了 (沒選紐西蘭的原因是因為我懶得抽籤，而且比起跟朋友一起出發，我更想要挑戰自己一個人出去旅行闖一闖)。

### **兩年澳洲打工度假: 旅館清潔、夜市小吃攤、麥當勞、餐廳服務生、蘋果農場包裝、超市生鮮區員工**

我的澳洲打工度假第一站是達爾文，很多人聽到之後都相當驚訝，但我覺得如果我第一站不選達爾文，我這輩子應該是不會去那個地方了。

在達爾文我做過旅館清潔、夜市小吃攤、餐廳服務生，後來幸運通過麥當勞面試，拿到了人人稱羨的高薪工作 (對於其他打工度假的人而言啦)

待了半年後，我開始覺得澳洲的生活好像不過如此，於是我規劃了一個的獨旅，去了阿德雷德、墨爾本、塔斯馬尼亞、紐西蘭南島。

途中遇到了很多有趣的人事物，這時候我才開始認真考慮要集二簽，於是在朋友介紹下到墨爾本郊區的蘋果農場打工。

農場的生活真的非常有趣，小小的農場充斥著各種背包客的愛恨情仇XD 同時認識了非常多一輩子的朋友，是我非常珍惜的一段時光！

二簽第一站我選擇了伯斯，理由跟一簽時一樣，因為覺得如果我那時候沒去，之後也不會再去這個地方了XD 

我在伯斯待了整整一年，做的也是令其他背包客稱羨的高薪超市工作。

在伯斯的生活讓我體驗到，如果擁有一份穩定的正職工作，在澳洲其實就可以過著相當優閒舒適的生活，不僅可以有著不錯的生活水平，還可以年年出國旅遊，只要努力存錢個幾年，就算靠我自己一個人的薪水，在澳洲擁有自己的小屋也不是夢想（相較於在台北買房的遙不可及）。

### **研究所: 台師大翻譯所休學**

打工度假結束後，我按照計畫回台灣讀翻譯所。

讀著讀著我突然覺得台北好吵又好擠，我懷念澳洲的生活。於是我決定回澳洲讀書，看看有沒有機會留在那裡。記得那時候跟我媽說這個決定時，她問我「你為什麼就不能好好待在台灣呢?才剛回來一年，就一定要再出去嗎?」

事實證明小時候真的不能太放任小朋友，我爸媽從小就不太干涉我的決定，也從來沒逼過我讀書 (小時候聽到其他小朋友的爸媽都會盯他們的功課覺得很神奇)，因為小時候管不了，等我長大擁有經濟能力之後就更管不了了XD

如同我填大學志願的時候完全按照自己的想法亂來，後來決定要來澳洲打工度假 (當年我媽也是反對的)、留學甚至是決定移民、轉職都是我自己決定的，想怪別人都沒辦法哈哈

### **澳洲留學: 麥考瑞大學研究生文憑(翻譯)、維多利亞大學研究生文憑(會計)、澳洲國立大學研究生文憑(澳洲移民法)**

在澳洲我其實念了好幾個學位XD

澳洲的學制跟台灣不同，台灣就是大學之後接著讀研究所，拿碩士學位。在澳洲，研究所學位可以分成好幾個階段，每一個階段都有學位證書：讀完半年是 Postgraduate Certificate、讀完一年是 Postgraduate Diploma，讀完 2–3 年則是一個完整的 Master Degree。

當時我常被朋友笑說「文、法、商你都讀了，下一個還要讀什麼?」(殊不知後來為了轉職我又讀了 IT 哈哈哈)

會讀這麼多個學位，是因為翻譯一開始是我的興趣，後來為了移民而改讀會計。移民法也是因為工作相關而產生的興趣，但我後來決定不要繼續往這個方向發展。

### **澳洲職場 (文書人員): 移民仲介顧問、會計職業評估師**

畢業後我幸運的拿到澳洲 PR ！後來讓我成功移民澳洲的其實不是我的會計學位，而是靠自己研究澳洲政府的移民法規中一個大多數人都會略過申請規定，靠著不在移民清單上的口譯專業申請到了新州 190 的永居 PR XD 詳細故事可以看這篇：[**機會由自己創造！我透過閱讀澳洲政府的移民規定成功移民澳洲！**](/posts/2023-11-10-how-i-become-pr/)

在澳洲留學時，我當時的房東開了一家移民仲介，知道我在找工讀機會，於是就決定讓我去試試。這個工作我斷斷續續可能也做了兩年。這是一家華人老闆開的仲介、所有同事跟客戶都是華人，看過了很多移民仲介的秘辛不說，在這種壓榨式環境工作真的是讓我懷疑起我來澳洲幹嘛?XD

不過這個經驗也讓我後來順利找到 Chartered Accountants ANZ (紐澳會計師職業協會) 的評估師工作。

這個工作算是開啟了我第一次在澳洲白人公司的全職工作經驗，在這裡我學到了很多職場英文跟澳洲的白領職場文化，算是我的辦公室英文急速成長的時段。

### **決定轉職**

在紐澳會計師職業協會的工作很輕鬆！

過了半年之後，我已經被升職為 senior assessor，但在此同時，我環顧四周，同事們大多都是一些 40–70 歲的阿姨奶奶們，每天重複做著文書處理的工作，沒有辦法在專業能力上有所進展，我不禁懷疑，這真的是 20 幾歲的我要的嗎? 

未來 40 年的職場生活，我能一直在這種工作崗位做下去嗎? 

當時的我身為 senior assessor，年薪大概是澳幣七萬，如果我再繼續做 10–20 年，我的薪資會有所成長嗎? 我覺得好像不行…… 

在此同時，澳洲理工科畢業生的起薪可能就是澳幣六萬五，大概不出一年他們的薪水就會超越我，未來更是有可能進展到十萬年薪或更多。

這個想法其實在我心中迴盪了許久，最後我還是決定裸辭，跑去讀程式訓練營 (Coding Bootcamp)，往網頁工程師的方向前進。詳情可以參考這篇: [**文組轉職澳洲 IT 工程師，我靠 Coding Bootcamp 進了 Amazon 當工程師！**](/posts/2022-12-03-bootcamp-to-aws/)

我辭職的那段時間完全沒有跟我的家人說(因為不想讓他們擔心)，甚至連身邊大多數朋友都不知道，只有少數幾個要好的朋友知道，因為當時的我其實根本不知道自己能不能轉職成功，如果失敗之後我該怎麼辦?

### **進入澳洲科技業: Amazon/AWS、微軟**

Coding bootcamp 畢業時剛好遇到 Covid，找工作非常困難，我在三個月的求職過程中投了 200 份履歷，最後只成功拿到一份 offer，就是 AWS! 

而且這份工作也不是網頁工程師，而是雲服務的科技顧問 (在 AWS 裡叫做 Cloud Architect)，詳細的工作內容可以參考這篇:[**澳洲亞馬遜 AWS Professional Services Cloud Architect 工作內容分享**](/posts/2022-12-23-aws-ps-ca/)

雖然很幸運拿到 AWS 的 offer，成功加入大型科技公司，但那段時間我其實過得非常辛苦，一直處於冒牌者症候群 (Imposter Syndrome) 的壓力之下，變得非常不快樂。

但我在 AWS 其實認識了非常多超級厲害、超級聰明，同時人也超級好的同事，不過因為心理壓力太大了，後來有機會跳槽，我也是毫不猶豫就決定加入微軟。

加入微軟後，意外發現 CSA (Cloud Solution Architect) 這個職位其實跟我個人的職涯目標也不是太一致XDDDD 我反倒開始想念起 AWS 的同事跟當時的工作，雖然辛苦，但至少是一個讓我在專業能力上會有所成長的工作。

很多時候，我其實也不知道未來要往那裡走，雖然每個決定我都是深思熟慮、做完各種分析比較之後才下的決定，但真的有時候還是不禁會懷疑自己是不是做錯了XD 但這就是人生吧？如果不去嘗試，就永遠不會知道結果。

### **結語**

從一開始打工度假到現在，我在澳洲已經生活超過十年! 

想想時間真的過得很快，一路從打工度假、留學到移民，一切完全就靠自己一個人完成。

過程中我遇到了很多貴人跟好朋友，也體驗過各式各樣的新鮮事，一路走來我真的學習到很多澳洲文化，也同時反思自己的台灣人思維。

就職涯來說，從專案經理/筆譯、移民仲介、澳洲辦公室白領到後來決定轉職工程師，最後居然還幸運了加入 Amazon & Microsoft 這種世界一流的公司，完全都是當年的我沒有想過的! 這麼一想我突然覺得自己好厲害！！！！

看完 EC 的故事，有沒有覺得人生就是由一連串的巧合與選擇所組成的？哈哈
