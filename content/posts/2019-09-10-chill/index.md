### 2019-09-09
繼上週結束了 Ruby，今天我們開始教HTML，全班感覺都很 chill XD (感覺之前學過 HTML & CSS的人不少，可能有超過一半以上，但我旁邊的馬克小哥倒是沒學過XD)

**大家都是 code stalkers**

今天發現有偷窺特質的不只是里奇大哥一人! 我旁邊的馬克小哥也在偷窺雷根小弟在 GitHub 上的 code，然後發誓要學會雷根小弟所使用的技巧。我走到廚房又不小心聽到馬克小哥跟加拿大戴爾小哥的對話，戴爾小哥說「喔~ 我週末就在家研究雷根的 code 啊!」我真心在旁邊要笑死😆😆😆 (雷根小弟表示「大家可以不要再偷窺我了嗎QAQ」)

**今日 Kahoot**

今天的 kahoot! 我是第二名、馬克第三，因為有一題老師設錯答案，不然誰會拿到第一名的其實還很難說? (某題的選項A跟都一樣是3，但老師只設定選A是答對，全班只有2個人選A，其中一個就是第一名的湯姆，我跟馬克都很衰地選C哈哈)

今天靠自己的力量解出兩題練習題(一題是今天早上的練習，一題是第二週的殘留lol)，覺得感動!!! QAQ

**coding meetup**

下課後留下來等著參加老師跟助教舉辦的 coding meetup，這次的主題是 linux file permission，覺得滿有趣的。不過五點下課，要撐到六點半才開始，覺得有點久LOL 而且這個 meetup 提供了披薩，卻沒有提供啤酒!!! 這怎麼可以!!! 而且不要說沒有啤酒了啦，連飲料都沒有，大家還要到廚房裝水喝，也太慘了吧😂 (害我差點想跑去買啤酒喝哈哈哈哈)

好笑的是，偉恩大哥真心是披薩吃完就走了(好險來參加的人滿多的，應該有 30-40 個，老師應該不會發現?) 

今天也看到了許久不見的 Su!!! 短暫得聊了一下覺得非常開心~ 然後我們班的同學好像都沒有特別去跟別人 social，默默自己圍成一圈閒聊!!! 最好笑的是，雷根小弟比較晚加入，他一跑過來就立刻說「快讓我也加入這個舒適圈~」，看來也不是每個澳洲人都熱愛social? 哈哈 (我沒有特地加入小圈圈，因為我一開始就在圈圈裡LOL)

### 2019-09-10
今天全班持續 chill 中，不到五點幾乎大家都走光光了! 我4:50走時大概只剩下三個同學還在教室XD

**原來 networking 也可以很有趣**

今天早上另一個老師來跟我們講解 networking!

實不相瞞其實我本來覺得做 networks & systems 的工作感覺應該很無聊，但今天這個老師真心是從頭到尾都展現了無比的熱情，完全翻轉了我的想法，講的知識很實用(很多都是我們第三個作業裡要回答的概念)，老師本人也超級幽默! 

不過可能是因為太少 hands-on 的部分了，兩個小時的演講之中我一直很努力在抵抗自己的睡意😂

**加入小弟弟們的桌遊團**

今天中午受桌遊團小弟們之邀加入了他們的桌遊(其實我只是站在旁邊等著微波午餐，但他們人數不足哈哈)，玩了人生第一場 Bang!
發現好像也沒有我想像中的困難? 

記得很久以前我玩過一次盜版 Bang!(i.e. 三國殺)，整個搞到我很困惑XD 

而且小弟弟們感覺人都滿好的~ PS: 最近又增加了一個我喜歡的人類，讓我們稱呼他為路克小弟!

我後來發現路克小弟人超好的啦!!!! 很樂於分享跟幫忙，屬於個性溫和中又帶點幽默詼諧的那種!

還記得我第一次贏得 Kahoot! 的時候播了 Kpop 嗎? 我當時以為全班沒人知道Kpop，昨天才發現路克小弟是澳韓混血Orz

**centrelink allowance**

今天的大好消息是我的 centrelink allowance 下了!!!
感恩上蒼~~~ 果然事先調查好遊戲規則很重要LOL 不過說真的，一週可以拿近$300澳的補助看似很多，但其實根本連我的房租都不夠付耶XDDD (一週花$350租 studio 的我囧)。

但不管怎樣，還是聊勝於無 (我之前一直覺得很有可能被拒哈哈)。

畢竟我之前工作的時候也繳了不少稅，現在全職讀書無法工作了，澳洲政府應該還是多少應該要照顧我一下吧😀
