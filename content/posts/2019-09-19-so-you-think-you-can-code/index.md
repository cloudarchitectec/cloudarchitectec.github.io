## 2019-09-19

每次的 project week 我的日記就會變週記XD

之前有個印象就是大家都覺得 web development/web design 很容易，還有人說 html 跟 CSS 根本不是「程式語言」，害我一直也覺得這件事沒這麼難吧! 結果根本大錯特錯!!!!!
那些說很簡單的人，要嘛是高手，要嘛就是用網站模板做的吧? 要自己從頭手刻一個網站跟本超難的好嗎!!!
難到連我旁邊的馬克都跟我說了好幾次「EC, life’s hard, right?」，然後我跟馬克說我最近的座右銘就是 「Life’s hard, but EC is trying her
best!」……真心覺得活著也太難了吧XDDD

總之這幾天我都是跟里奇大哥或偉恩大哥一起搭火車回家，他們好像對助教的實力有所不滿XD 我本來是覺得還好，直到昨天我問了助教兩個問題，第一個他用了一個方法解決(但後來發現其實沒有解決，於是我又去問老師，結果老師對於助教的解法深深表示不以為然XD)，第二個他搞超久都解決不了，只能一直估狗，害我覺得自己好像霸佔助教太久，對其他同學感到很不好意思(但其實不是我的問題，而且他自己解不出來啊XDD)
然後我去找老師解第一個問題時，老師看到我的設計(第二個問題)，居然說「天啊! 我從來不知道你可以這樣做!!! 所以如果你的問題是關於這個的話，最好不要問我，不然我也只能跟你估狗了LOL」(what
the… 原來這個對我很難的東西，對老師跟助教也是不解之謎嗎?哈哈哈)

不過偷偷說，放學後里奇大哥跟戴爾大哥看了一下，他們幫我解決了大概90%的部分(剩下10%雖然不完美，但在可忍受的範圍內!)，所以他們兩個根本殺爆老師(有八年業界經驗)跟助教😆😆😆
然後就回到偉恩大哥跟我的抱怨，偉恩大哥覺得網頁設計我們根本沒教多少(約一個禮拜，但我們每天lecture
的時間大概只有3小時，也就是大約上了15個小時)，就要我們從頭到尾，從規劃到設計到coding出一個網站! (我們的第一個 terminal app 作業，我們至少是教了三個禮拜，經過無數個小練習之後才要求我們在三天內做出來)。他說「我都付了20K來上這個課，結果回家還要自己看 udemy 的課程補基礎知識? 我操!」(因為當下只有我們兩個人，所以他講一講直接冒中文髒話，快笑死XDDD)

PS: 其實這幾天我又大崩潰了一次，這篇是我調整完心態寫的ＸＤ
