## 2019-09-19

**人生好難**

每次到了作業週，我的日記就會變週記XD

之前有個印象就是大家都覺得網頁開發/網頁程式設計很容易，還有人說 HTML 跟 CSS 根本不能算是「程式語言」，導致我一直也覺得這件事沒這麼難吧! 結果根本大錯特錯!!!!!

那些說很簡單的人，要嘛是高手，要嘛就是用網站模板做的吧? 要自己從頭手刻一個網站根本超難的好嗎!!!

難到連我旁邊的馬克都跟我說了好幾次「EC 人生好難喔～ (EC, life’s hard, right?)」

我回馬克說我最近的座右銘就是 「人生很難，但 EC 全力以赴中 (Life’s hard, but EC is trying her best!)」……真心覺得人活著也太難了吧XDDD

**助教的實力？**

這幾天我都是跟里奇大哥或偉恩大哥一起搭火車回家，他們好像對助教的實力有所不滿XD 

我本來覺得還好，直到昨天我問了助教兩個問題：

第一個他用了一個方法解決，但後來發現其實沒有解決，於是我又去問老師，結果老師對於助教的解法深深表示不以為然XD

第二個他搞超久都解決不了，只能一直估狗，害我覺得自己好像霸佔助教太久，對其他同學感到很不好意思(但不是我的問題啊，而且他自己解不出來XDD)

然後我去找老師解第一個問題時，老師看到我的第二個問題的思路，居然說「天啊! 我從來不知道你可以這樣做!!! 所以如果你的問題是關於這個的話，最好不要問我，不然我也只能估狗了LOL」

(什麼？！原來這個對我很難的東西，對老師跟助教也是不解之謎嗎?哈哈哈)

偷偷說，放學後里奇大哥跟戴爾小哥看了一下，他們幫我解決了大概 90% 的問題(剩下 10% 雖然不完美，但在可忍受的範圍內!)，所以他們兩個根本殺爆老師(有八年業界經驗)跟助教😆😆😆

**寫作業寫到崩潰的還有偉恩大哥**

然後回到偉恩大哥跟我的抱怨，偉恩大哥覺得網頁設計老師根本就沒有教教多少，就要我們從頭到尾、從規劃到設計到手刻出一個網站，也太強人所難!

(網頁設計我們大概學了一個禮拜，但我們每天上課的時間大概只有 3 小時，也就是大約上了 15 個小時)

我們的第一個 terminal app 作業，我們至少是教了三個禮拜，經過無數個小練習之後才要求我們在三天內做出來。

偉恩大哥說「我都付了兩萬澳幣來上這個課程，結果回家還要自己看 Udemy 的課程補基礎知識? 我操!」(因為當下只有我們兩個人，所以他講一講直接冒中文髒話，快笑死XDDD)

PS: 其實這幾天我又大崩潰了一次，這篇是我調整完心態寫的XD 是不是很平靜？😌

## 2019-09-20 與週末

**越改越心驚膽戰**

我剛剛交了作業，很開心～

是說死線是今晚 10 點，強迫症患者我通常都會一直改到最後一刻再交，但這次為什麼這麼早交呢 (現在是下午兩點)?

因為今天早上我一起來，發現我昨天做好的網站，整個大~崩~壞！是崩到整個格式都跑掉而且救不回來的那種😭 

然後我驚慌失措地搶救了兩個小時(說實話，我根本不知道該如何搶救起，因為整個 code 都壞啦~我也不知道是壞在哪😂)

目前好像救回來了? 但我也不是完全確定它現在到底是壞的，還是我救回來了? 所以我就決定再也不要碰我的 code 了 😅！

把剩下 documentation 的部分改一改我就交了，然後祈禱吧 (hope for the best?) XDDDDD

**一開始還覺得自己有餘裕**

時間回到星期五，這次作業我這次決定先做 documentation 的部分，所以第一天我完全過得輕鬆寫意

第二天開始寫程式後發現「等等，事情完全不是我計畫的那樣啊啊啊啊」，

第二天跟第三天我的網站真心就是💩 中之 💩，尤其是到了第三天，很多同學都已經把整個網站的架構做完了，剩下稍微修改格式跟放文字而已

那時候我還在做首頁的其中一個元素而已呢!!! (甚至還不是一個完整的網頁囧)

**天使小哥你！**

某天早上我搭電梯遇到天使小哥，他問我網站進度如何，我直接回說「crap💩」! 他好心地回我說「喔~我可以幫你啊! 你要是有什麼問題就直接來找我吧~」 

天使小哥真心是大好人!!!! (雖然他明顯思維異於常人，很多時候講的話題大家都接不上😆) 

然後受到這個鼓舞，於是我立馬跑去問他一個東西，然後他看著我的 code 搔搔頭跟我說「恩……其實我不是很會看其他人寫的程式碼」 

天使小哥你XDDDDDD 說好的友誼之手呢XDDD 我當下整個人內心快笑死哈哈(不過他後來還是有幫到我啦～)

**獲得里奇大哥的大大好評**

我星期四晚上崩潰完，星期五早上調整好心態(重點不是我要做出一個多棒的網站，而是我要把我學到的東西展現出來! 如果發現我做出來的網站很爛，那也就只是表示我現在就只學會這樣而已，沒什麼好怕的😁)

到了星期五晚上我整個進度突飛猛進，把整個網站做完了，還做了好幾個效果(花黑噴?)XD

週六我好好把網站設計的部分修了一修，結果我在跟里奇大哥討論作業時，他無意間看到我的網站他說 

「哇！你的網站看起來進步好多！你的「關於我」頁面現在可以放大縮小...等等你還在 projects 頁放了投影片效果！！！可惡，那個工作經驗頁面上的翻卡牌效果也太酷了吧，現在我開始討厭你了！」

(Your site has a much better look now! And you have this zoom in effect on your ‘about me’ page, and wait you also got a slideshow effect on your projects page? 
Damn, the flip card effect on your experiences page is so cool! Now I hate you 😊”  )
 
我整個快被他的反應笑死XDD

**耍了一點(借來的)花活**

但說實話，我看了幾個同學做的網站，我必須說里奇大哥的網站是我心中的第一名（還記得上次的程式作業他的作品也是我的第一名嗎？XD）

網站設計、顏色搭配、字型、圖案運用真心都太完美了！！！我的網站完全就是花招取勝😆

很多我都還是按照網路教學複製貼上，然後改一改而已😂　

但其實改一改也不簡單，我那天光要改箭頭位置跟翻卡的方向大概也都各花了我一個小時😂

**週末狂改作業**

週六我就一邊跟里奇大哥跟偉恩大哥在 Slack 上討論加一邊繼續修網站，結果他們兩個狂飆髒話，超好笑的。

例子一：

里奇大哥問我說「EC～我看好多同學（跟你）都把你們的程式檔放在一個叫 src 的程式夾裡，是個人選擇嗎？還是老師上課有講？」

我「嗯～這個東西不是列在作業規定裡嗎？(然後傳評分標準的截圖給他)」

里奇大哥直接回我「fxxx」XD　

然後他為了把檔案移到這個資料夾，他就損失了所有的 github commits，這個作業大概要有 30 個 github commits，太慘了！！！

我最討厭 coding 的地方就是，處處是危機啊！你只要不小心移動了檔案，或是不小心打了一個字母，就可能造成無法抹滅的結果～哭

例子二：

偉恩大哥問我「所以 git branching 是要幹嘛的？」

我稍微解釋了一下，他說「喔喔～所以是以後做 project 時要用，這次不用管對吧？」

我說「沒有啊～你看某個評分標準(然後傳評分標準的截圖給他)，這次的作業就要評這個啊」

偉恩大哥「fxxx！」XD

其實比起第一個程式作業有二十幾條評分標準，這次的網站作業只有十幾條，但實在還是太複雜了！

我個人大概前前後後讀了十遍，結果我週六時還是發現有我漏掉的地方，好險不是什麼大問題～

今天下午我要趕快來隨便把第三個作業寫完，然後準備下週迎接我的好朋友Ｗ的到來～～～

下週五我們要一起幫朋友慶生，週六要去參加婚禮，好忙好忙啊～　然後下週居然又有另一個作業 due 😦
