2019-09-25 戴爾小哥



今天實在有太多講座環節了，總共有兩個同學、加一個老師，再加上一個導師談話 (mentor talk)，搞到我最後比寫程式一整天還累LOL

我特別喜歡加拿大小哥戴爾小哥的演講，就像他說的，在今天之前我甚至都不知道加拿大有原住民!

我覺得文化意識跟國家/民族認同意識這種東西，果然只有經歷過的人才會懂 (今天聽他的演講我覺得感觸超深的，一直想到台灣的原住民也是這樣被強迫漢化)!

之前偉恩大哥傳了一個搞笑影片給大家看(算是有點惡搞越南/亞洲文化吧~ 影片其實還算有趣啦)

但戴爾小哥聽完主題就直接說「這感覺有點敏感呢! 恩~ 我還是不看了吧」

我覺得當你有這種文化意識時，你應該就會特別尊重其他人的文化，因為你會希望大家也尊重你的文化!所以我非常欣賞戴爾小哥!!!

#### 複習 Ruby

我們今天結束所有演講就已經兩三點了，然後老師說我們今天不教新內容，要好好來把我們之前教過的所有 ruby 概念再複習一次! 

我在心中冷笑說「哈哈~ 你們之前進度教得飛起吧，現在發現程度在後面的同學遠遠跟不上了吧! 現在才開始放慢速度補救，真的補得回來嗎?」

而且等於我們這週一到週三都完全沒教新內容(週一裝軟體、週二 presentation、週三一堆 talks 加複習)，

這樣接下來是不是教新內容的時間又要被壓縮? 然後大家舊的還沒撿起來，新的又繼續趕不上?

其實最近這一兩週開始我對於這個課程的設計開始產生巨大的懷疑!(不知道是不是因為我太常跟懷疑論者里奇大哥&功利主義者偉恩大哥鬼混了?😆) 

感覺我們花了很多時間在不重要的事情上，太多各式演講了(其實我覺得立意很好，但數量也太多了吧)

作業裡說明 (documentation) 的部分佔比分也太重

該花時間的部分，老師感覺又沒有特別加強，例如很多時候我們根本連對基本概念都懵懵懂懂，但就已經到了我們要自己獨立做出一個 app 或寫出一個網站的時候了? 

臣妾真的辦不到啊!!! 😂 (雖然說是這樣說，我最後也還是做出來了啦哈哈哈)

#### 公布首次作業成績

今天也收到我第一個程式作業的成績了，我只拿了 85/130.5，換算成百分比大概 65%，在澳洲大概是 credit (中上) 的程度

澳洲成績級距分別為： 
- fail 49%
- pass 50-59%
- credit 60-69%
- distinction 70-79%
- high distinction 80-100%

(這個打分系統簡直是亞洲資優生的噩夢，我們是連少拿一分都要斤斤計較的群體耶！澳洲 HD 是很難取得的，可能一班裡面只會有 1-3 個那種)

我覺得不是特別滿意，但其實仔細想想，我的作品說實在最多也就是這個分數吧XDD 

能拿到 credit 說不定還是因為文件的部分佔很重，然後我文件寫得還可以？

我覺得最搞笑的是，老師的評語裡有一句說「我覺得你好像花太多時間在設計程式了，所以沒時間做 error handling? 

我發現了好幾個 bugs，雖然你的程式也不會因此跑不了啦!」

我心想「你以為我不知道那裡有 errors 嗎? 我知道啊!!!! 但我沒辦法做得更好了!!! 我所學到的東西就只有這樣啊XDDD 這就是我全部的實力!!!」

而且其實 presentation 結束後，我就立馬就抓緊時間去問了助教，

因為我知道這邊 error handling 做得不是太好，結果助教跟我說「就一般程式來說，我覺得你做到這樣已經不錯了，不用再加了~」，

也沒有再進一步跟我說可以再怎麼改進LOL

結果就是評分老師在這一個單項給我的分數是 2/12 (12 分裡面只給我 2 分，好狠的心啊😂😂😂)

這個改作業的老師不是教我們的老師或助教，其實我覺得她的 ruby 實力感覺也不是太強

有一次她自願來下午的練習時間幫忙，結果我問了她一個極為簡單的問題，她在那邊跟我弄了半天都解決不出來

後來還是我問了旁邊的馬克，馬克立馬就指出錯誤好嗎XDD

2019-09-26

#### 幾乎每個人都不開心的評分結果

一早來發現所有人都對第一個程式作業的分數感到相當不開心XDD

就連做作業時完全遵照 HD 標準在做的馬克(澳洲公布作業時會有公開的評分標準可參考)，最後也沒拿到 HD! 

但馬克可能是我知道的人裡面心態最平穩的一個XD 

我發現馬克雖然是很好勝心很強的人格，但他似乎不是跟別人衝突的那種! 好羨慕聰明又淡定的人啊 QQ

其他很不高興的人，例如加拿大戴爾小哥，聽說他甚至想要退出 bootcamp! 

加拿大小哥的 app 做得超好耶!!! 但聽偉恩大哥說他拿的分數好像比我還低? QAQ

里奇大哥 (他好像氣到整晚跟偉恩大哥抱怨，然後完全沒睡好，今天一來完全呈現一個「別跟我說話」的低氣壓)

凱西小姐也很不開心(我跟凱西小姐的分數差不多，但她的態度算是比較正面的那種，只說要去找評分老師當面談談，搞清楚是哪裡沒做好，至少下次可以改進)。

我特意跑過去後面跟雷根小弟對話，然後證實全班分數最高(115.5)的果然是他XD 

#### 過度嚴苛的標準

說實話我覺得評分標準很嚴苛，最低分的人拿了 64，滿分是 130.5，也就是說評分老師居然寧願讓那個人不及格，也不願意給他多個 1.5 分????? 

說真的，64 分跟 65.5 分的表現根本沒差吧? 但反映在成績上，就是及格與否的差異耶!!!!! 

我真心不懂有什麼理由這麼狠心以 1.5 分的差距讓一個人不及格 (重申：澳洲的及格標準是 50%)?

今天恢復正常課程進度，開始教新內容，結果又是一個因為大家基礎沒打穩，全班跟得霧煞煞的一天

連我旁邊的馬克都直接跟我說「不好意思我沒跟上」冏，後來還是我跟他說最後一行 code 是什麼。

讓我真心懷疑這樣真的好嗎? 必須說，如果連馬克都沒跟上，那誰跟得上啦XDD (雖然馬克下午好像很快就自己領悟了XD) 

前幾屆的同學，都沒有反應過這樣的教學方式有問題嗎? 我真心覺得全班跟得上的人可能只有不到五個耶! (當然我並不在那五個人裡面ㄎㄎ)

然後接下來我們就要這樣一直堆疊下去嗎? 前面說到戴爾小哥想退學，其實我也開始想退學XD 

只可惜我當初是直接遞辭呈，現在已經完全沒有退路XD 要是我當初只是留職停薪或讀在職專班，我可能真的會直接退學也不一定XD 因為這不是我想要的啊~ 

我要是從現在就沒完全跟上，就靠那 50-60% 理解(更別提有時候我甚至只懂 30-40% 好嗎) 混過整個課程，真的有意義嗎?😂

# 唉

今天老師又開始額外的複習課程，苦苦掙扎的我立刻就去了。結果中間我提問了一個問題，老師完全勃然大怒XDDD

之前里奇大哥也是在課堂上不小心碰觸到這個概念，老師也是直接在全班面前變臉LOL 

事後我問里奇大哥他當下有沒有嚇到，他說「沒有，但是我很不爽!!! 我只是提出一個可能性，又不是說這樣做就是對的」

害我當下眼眶就紅了🥺

我重提這件議題並不是想挑戰老師的權威，只是老師一直說叫我們不要用 global variables，用 local variables 跟 instance variables 就好

但是他解釋 instance variables 的時候解釋得非常不清楚

所以我只是說「那 local variables 我懂了，那 instance variables 跟 global variables 的範圍到底有哪裡不同?」

然後老師就大生氣說「我不是說過不要提 global variables 嗎? 為什麼每個人都要提 global variables?」 

我不想問 global variables 啊！

但是你可以好好說清楚 instance variables 可以應用的範圍在哪嗎??? 

如果沒差的話，那 instance variables 可應用的範圍是不是跟 global 基本一樣???

總之我非常不開心! 

回到教室時大概 4:50，但是還有很多同學在奮戰，我直接收拾書包，轉頭跟偉恩大哥用中文說「我剛剛問問題被老師罵了，我非常不開心😭，我要走了」然後我就走了XDDD

# 期待放假去里奇大哥家玩 (讀作：學習)

回家後我傳訊給里奇大哥，他之前上過 NSW TAFE 的 IT diploma ，但他後來退選了(他說 75% 的學生學到一半都直接退課!)

我就問他說「那你有想過要退我們這個 bootcamp 嗎?」他回「沒有! 等等，你為什麼問這個? 拜託不要告訴我你想退選! Please don’t!!!」😆

總之，最後里奇大哥問我放假有沒有什麼計畫，他邀請大家(i.e. 我、偉恩大哥、馬克)一起去他家讀書會，讓我感受到莫大的安慰!!! 

我跟他說「就衝著你這份心意，我會多堅持一下的~」 

雖然我不知道這個邀約會不會成功(其實我覺得不會XD)，但我還是對於他的善意感到非常感動!

PS: 不過我不知道里奇大哥居然也覺得馬克是他的課堂好朋友?XD 偉恩大哥一直覺得馬克太獨來獨往，不是很好! 

我每次都回說「這樣有什麼不好?而且他也不是完全不跟別人講話啊? 你問他問題他會回，見面會打招呼、離開會說再見，要跟他閒聊，他也是會跟你聊幾句啊?」

對於我這種不喜歡跟陌生人交流的人來說「你們這種做什麼事都喜歡一群人的人才奇怪咧XDDD」 (I 人跟 E 人之間果然很難互相理解🤣🤣🤣)
