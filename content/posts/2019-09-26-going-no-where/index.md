### 2019-09-26

一早來發現所有人都對第一個程式作業的分數感到相當不開心XDD

就連做作業時完全遵照 HD 標準在做的馬克(澳洲公布作業時會有公開的評分標準可參考)，最後也沒拿到 HD! 但馬克可能是我知道的人裡面最不upset 的一個XD (我發現馬克雖然是很 competitive 的人格，但他似乎不是 confronting 的那種! 好羨慕聰明又 chill 的人啊QQ)

其他很不高興的人，例如加拿大戴爾小哥(聽說他甚至想要 quit bootcamp! 加拿大小哥的 app 做得超好耶!!! 但聽偉恩大哥說他拿的分數好像比我還低? QAQ)、里奇大哥 (他好像氣到整晚跟偉恩大哥抱怨，然後完全沒睡好，今天一來完全呈現一個「別跟我說話」的低氣壓)、凱西小姐也很不開心(我跟凱西小姐的分數差不多，但她的態度算是比較正面的那種，只說要去找評分老師當面談談，搞清楚是哪裡沒做好，至少下次可以改進)。

我特意跑過去後面跟雷根小弟對話，然後證實全班分數最高(115.5)的果然是他XD 

說實話我覺得評分標準很 harsh，最低分的人拿了 64，滿分是130.5，也就是說評分老師居然寧願讓那個人 fail，也不願意給他多個 1.5分????? 說真的，64分跟65.5分的表現根本沒差吧? 但反映在成績上，一個就是 fail 一個就是 pass 耶!!!!! 我真心不懂有什麼理由這麼狠心以1.5分的差距 fail 一個人 (澳洲 pass標準是 50%)?

今天恢復正常課程進度，開始教新內容，結果又是一個因為大家基礎沒打穩，全班跟得霧薩薩的一天，連我旁邊的馬克都直接跟我說「sorry 我沒跟上」冏，後來還是我跟他說最後一行 code 是什麼。

讓我真心懷疑這樣真的好嗎? 必須說，如果連馬克都沒跟上，那誰跟得上啦XDD (雖然馬克下午好像很快就自己 picked up了XD) 之前的 cohort 按照同樣的教學方式，都沒有這個問題嗎? 我真心覺得全班跟得上的人可能只有不到五個耶! (當然我並不在那五個人裡面ㄎㄎ)

然後接下來我們就要這樣一直堆疊下去嗎? 前面說到戴爾小哥想 quit，其實我也開始想 quit XD (只可惜我當初是直接遞辭呈，現在已經完全沒有退路XD 要是我當初只是留職停薪或讀 part-time，我可能真的會直接 quit 也不一定XD) 因為這不是我想要得啊~ 我要是從現在就沒完全跟上，就靠那 50-60% understanding (更別提有時候我甚至只懂30-40%好嗎) 混過整個，真的有意義嗎?😂

今天老師又開始額外的複習課程，苦苦掙扎的我立刻就去了。結果中間我提問了一個問題，老師完全勃然大怒XDDD (之前里奇大哥也是在課堂上不小心碰觸到這個概念，老師也是直接在全班面前變臉LOL 事後我問里奇大哥他當下有沒有嚇到，他說「沒有，但是我很不爽!!! 我只是提出一個可能性，又不是說這樣做就是對的」)

害我當下眼眶就紅了LOL

我重提這件議題並不是想挑戰老師的權威，只是老師一直說叫我們不要用 global variables，用local variables 跟 instance variables 就好，但是他解釋 instance variables 的時候解釋得非常不清楚，所以我只是說「那local variables我懂了，那 instance variables 跟 global variables 的範圍到底有哪裡不同?」

然後老師就大生氣說「我不是說過不要提global variables嗎? 為什麼每個人都要提global
variables?」 我不想問global variables啊~ 但是你可以好好說清楚 instance variables 可以應用的範圍在哪嗎??? 如果沒差的話，那 instance variables 可應用的範圍是不是跟 global 基本一樣???

總之我非常不開心! 回到教室時大概4:50，但是還有很多同學在奮戰，我直接收拾書包，轉頭跟偉恩大哥用中文說「我剛剛問問題被老師罵了，我非常不開心😭，我要走了」然後我就走了XDDD

回家後我傳訊給里奇大哥，他之前上過 NSW TAFE 的 IT diploma ，但他後來退選了(他說75%的學生學到一半都直接退課!)，我就問他說「那你有想過要退我們這個bootcamp嗎?」 他回「沒有! 等等，你為什麼問這個? 拜託不要告訴我你想退選! Please don’t!!!」 😆

總之，最後里奇大哥問我 term break 有沒有什麼計畫，他邀請大家(i.e. 我、偉恩大哥、馬克)一起去他家讀書會，讓我感受到莫大的安慰!!! 

我跟他說「就衝著你這份心意，我會多堅持一下的~」 雖然我不知道這個計畫會不會成功(其實我覺得不會XD)，但我還是對於他的善意感到非常感動!

PS: 不過我不知道里奇大哥居然也覺得馬克是他的課堂好朋友?XD 偉恩大哥一直覺得馬克太獨來獨往，不是很好! 我每次都回說「這樣有什麼不好?而且他也不是完全不跟別人講話啊? 你問他問題他也會回，見面會打招呼、離開會說再見，要跟他small talks 他也是會跟你聊啊?」(對於我這種不喜歡跟陌生人交流的人來說「你們這種做什麼事都喜歡一群人的人才奇怪咧XDDD」)
