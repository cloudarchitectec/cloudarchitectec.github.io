2019-10-01
今天教了API，下午老師要我們 pair programming。這次的練習 partner 不是自己選的，而是大家根據自己對於 API 的了解程度站出來排隊。覺得自己越了解的往左邊站，覺得自己越不了解的就往右邊站。
我本來覺得自己大概50%
50% 吧，就想站中間，結果不知道為什麼就越來越被人擠向左邊了 LOL 一開始馬克還想站我右邊，我心想「ㄟㄟ馬克你想幹嘛，怎麼看你都不可能站我右邊好嗎? 趕快去站左邊第一個啦XDDD」然後老師就把最了解的跟最不了解的配成一對，以此類推! 我的練習 partner 是艾力克斯小弟~ 艾力克斯小弟覺得他的了解程度也是 50%
50%。
事實證明，把兩個半懂不懂的人湊在一起，是做不出甚麼結果的XDDD 我們做到一半就發現班上同學有另一組在跟我們做幾乎一樣的東西，但是他們一下子就做出來了lol (因為他們那組有高人)  然後我們兩個瘋狂努力搞到最後才發現，這個東西在 windows users 身上是不可能發生的囧 (因為老師說mac的safari瀏覽器是內建的，跟電腦程式是連在一起的，所以他們可以用 terminal commands 開 browser，但我跟艾力克斯都是用 windows 囧)
此時距離 presentation 只有20 分鐘，老師叫我們想辦法在努力做一個。想當然我們花了一個下午都沒做出來的東西，怎麼可能在20分鐘內做出來，於是我們成為全班唯一一組沒有做出來的人哈哈哈哈哈哈
艾力克斯小弟一直到別人在發表作品的時候都還在奮戰，還要叫我看他寫的程式，所以有一半人的分享我都沒聽到(哭)!   其實我個人是覺得，既然都做不出來了，那就別管了吧，我想要知道同學們都做出了什麼有趣的東西啊LOL
下課後我們在偉恩大哥的號召之下，又跑到附近的bar去喝酒。成員有我、偉恩大哥、艾力克斯小弟跟天使小哥 (只差普拉德大哥一人，我們上次中午跑去
aldi 買啤酒的啤酒小隊就全員到齊了XD)。天使小哥待了一下就走了，我不知道為什麼偉恩大哥跟艾力克斯小弟聊一聊就開始聊奇怪的問題??? 不過他們兩個我都還算熟，所以也就算了!
經過今天這次酒吧搏感情，艾力克斯小弟的排名急速上升! 現在我在班上最熟的人已經變成偉恩大哥>里奇大哥>艾力克斯小弟了XD
