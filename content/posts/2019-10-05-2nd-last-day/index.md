2019-10-01

#### 分組解題

今天早上教了 API，下午老師要我們 pair programming。

這次的練習 partner 不是自己選的，而是大家根據自己對於 API 的了解程度站出來排隊：覺得自己越了解的往左邊站，覺得自己越不了解的就往右邊站。

我本來覺得自己大概 50% 吧，就想站中間，結果不知道為什麼就越來越被人擠向左邊了LOL 

一開始馬克還想站我右邊，我心想「ㄟㄟ馬克你想幹嘛，怎麼看你都不可能站我右邊好嗎? 趕快去站左邊第一個啦XDDD」

然後老師就把最了解的跟最不了解的配成一對，以此類推! 

我的練習夥伴是艾力克斯小弟~ 艾力克斯小弟覺得他的了解程度也是 50% 左右。

事實證明，把兩個半懂不懂的人湊在一起，是做不出什麼結果的XDDD 

我們做到一半就發現班上同學有另一組在跟我們做幾乎一樣的東西，但是他們一下子就做出來了lol (因為他們那組有高人) 

然後我們兩個瘋狂努力搞到最後才發現，這個東西在 Windows 電腦上是不可能發生的囧 

(後來老師解釋 Mac 電腦的瀏覽器(safari)是內建的原生系統，所以他們可以用 terminal commands 開瀏覽器，但我跟艾力克斯都是用 WSL，所以沒辦法😳)

此時距離 presentation 只有 20 分鐘，老師叫我們想辦法再努力做一個。

想當然我們花了一個下午都沒做出來的東西，怎麼可能在 20 分鐘內做出來，於是我們成為全班唯一一組沒有做出來的人哈哈哈哈哈哈 (太慘了 QQ)

艾力克斯小弟一直到別人在發表作品時都還在奮戰，還要叫我看他寫的程式，所以有一半人的分享我都沒聽到(哭)!  

其實我個人是覺得，既然都做不出來了，那就別管了吧，我想要知道同學們都做出了什麼有趣的東西啊XD

下課後我們在偉恩大哥的號召之下，又跑到附近的 bar 去喝酒。

成員有我、偉恩大哥、艾力克斯小弟跟天使小哥 (只差普拉德大哥一人，我們上次中午跑去 aldi 買啤酒的啤酒小隊就全員到齊了XD)。

天使小哥待了一下就走了，我不知道為什麼偉恩大哥跟艾力克斯小弟聊一聊就開始聊奇怪的問題??? 不過他們兩個我都還算熟，所以也就算了!

經過今天這次酒吧搏感情，艾力克斯小弟的排名急速上升! 

現在我在班上最熟的人已經變成偉恩大哥>里奇大哥>艾力克斯小弟了XD


2019-10-03

今天下午仍然是 pair programming 練習時間，這次我就學乖了，直接往右邊走(最不懂的那邊)，上次站中間我那個痛苦啊! 

兩個似懂非懂的人真心搞不出什麼東西，不如直接站右邊，等左邊的高手們來解救我吧哈哈

羅比小弟超好笑的，老師話還沒講完，他就直接站到最右邊，並且表示沒有人可以站在他右邊XDD

(一副在那邊管制交通的樣子，引導所有人只能從他左邊開始排😆)

這次我好像是從右邊數來第三個，然後與我配對的人是......雷根小弟!!!!!!!!!!!!! (目前班上公認的第一名~) 我超興奮的啦!!!

老師一宣布我就直接歡呼說「耶~ 我跟雷根小弟一組!!!」 (後來馬克跟偉恩大哥就幫我取了一個綽號叫「雷根小弟的頭號粉絲」，笑死我XDDD)

不得不說雷根小弟真心是個很好的人，完全一步一步引導我😇，但只能說姐姐我實在資質駑鈍，完全在那邊一知半解LOL

中間雷根小弟還一度對我感到很抱歉，他說「我希望我要是可以解釋得再好一點就好了」，我心想「我聽不懂肯定是我的問題啊~ 高手你請不要懷疑自己啊啊啊啊!」

跟隨著雷根小弟的腳步，我們大概四點半就做完了。做完時很高興，雷根小弟就跟我擊掌了一下，

然後老師不知道從哪跑出來也跟我們歡欣鼓舞地擊掌，我們立即獲得全班同學的目光，雷根小弟說「完了，大家又要開始討厭我了!」我說「哪會? 那是大家對你喜愛的眼光啊XD」 

要是忌妒班上最聰明的同學可以讓我也變得一樣聰明的話，我當然會這麼做! 

但並不會啊XDDD 誰要去忌妒班上第一名啊，趕快抱緊他的大腿更有用吧😆

後來雷根小弟不到五點就走了，我回到座位上，馬克默默對我說「我跟偉恩大哥(他們兩個一組)剛剛掙扎了很久……」

我心想「居然連馬克都覺得難嗎? 那要是我們不 pair programming 的話，我一個人哪做得出來LOL」 

雷根小弟只有一開始沒抓到一個新概念時糾結了一下(這很正常，因為老師從來沒教過這個)，後來寫 code 完全是霹靂啪啦就寫出來XDDD

戴爾小哥在旁邊也跟著幽幽地說「我記得昨天雷根小弟也是不到五點就寫完就走了…」

PS: 我本來我今天在雷根小弟薰陶之下，回家應該可以寫出昨天的練習吧(跟今天的很類似)，結果我回家後也沒解出來哈哈哈哈哈哈! 決定明天一早殺去問助教~

晚上在萬般糾結之下(下課後實在是太想回家了)，我還是去聽了另一個 coding bootcamp 的招生說明會 (跟雪梨大學一起聯名合辦)。

其實光聽說明會的話，好像還真的比較不出好壞，因為場面話人人都會說!

不過我在現場問了很多問題，也聽了其他人問了問題，然後根據我現在已經上到第七週的心得，我覺得這個跟大學聯名的 bootcamp 感覺不太妙XD 

...所以只能說我現在的 bootcamp 跟老師好像的確是最好的選擇，只是他們可能沒有達到我對兩萬澳幣(40 萬台幣)學費的期待而已😂😂😂
