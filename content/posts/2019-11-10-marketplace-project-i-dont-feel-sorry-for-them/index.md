### 2019-11-05
今天里奇大哥還是沒來學校，我已經開始覺得有點寂寞了LOL
(我們project
週通常沒課的，除非有同學要求，所以大家也只是來學校做 project
跟問老師和助教問題而已XD)
[其實我本來沒打算要寫以下抱怨XD]
但說到這個就不免抱怨一下，我上週一就問老師可不可以教我們做 transaction
table，老師答應了後就一直沒上，一直到上週四他還又問了我一次想學什麼，說他當天會教，結果也沒有。然後上週五我問他說是不是有 search
functions 的筆記沒上傳(我會這樣問是因為他之前自己說他發現有些他的筆記沒上傳到學習網上)，他說會找時間上傳，我週五晚上還傳訊息提醒他希望他週末可以上傳，結果也沒有科科
所以我週末就自己看了幾個 youtube
tutorials 把 simple
search & advanced search 做完了! 然後週一晚上我參考了馬克在
GitHub 上的code，把 transactions
table 也做完了 (最後遇到一點小問題，但早上問助教解決了)。
結果今天老師才突然說要上 search
functions……. 還說基本架構沒做完的人可以不要參加，因為 search
functions 只是 sprinkles。雖然我坐在台下上課，但想當然爾我完全無法專心，一是基本的 search
部份我早就做完了，現在在學也沒用(雖然老師有多教了一些youtube上沒教的東西，但我覺得我也沒時間把那些額外的部分應用到我的網站裡)，二是我覺得時間非常緊迫，感覺剩下的時間不多了，所以我就一邊做自己的事一邊聽，想當然爾效果不是太好。 上完之後老師突然想到就問我說「EC你是不是說想上transactions table? 要現在一起上嗎?」 我只好尷尬地說「厄~ 不用了，我已經做完了LOL」
里奇大哥這幾天也是對老師感到相當不滿，因為他覺得每次他問老師問題，老師都會回他說「你可以 google
xxx 關鍵字就好~」，但要是其他同學問老師一些基礎到不行的問題，老師就手把手帶著他們做，他覺得很不公平XD
其實我這幾天倒是沒有里奇大哥這麼生氣，因為我已經習慣了哈哈哈哈哈 (這就是我們花兩萬塊得到的待遇😂)
之前過我一直覺得自己在班上是墊底，不過現在我數了一下，覺得我現在已經上升到中段班了，因為後面落後的同學是真的很落後囧
然後我跟馬克昨天小聊了一下，我說「我覺得時間好緊繃啊」，馬克說「對啊我們兩個已經算進度很超前的了，都覺得很緊張，真心不知道那些連基本的框架都還沒做完的人是想怎樣?」
回家的路上我傳訊息到群組說「我今天做得太認真了，完全忘記吃午餐」，結果馬克說他也是XDDD
然後馬克說他最近覺得有點煩，因為有些同學會問他一些超級基本的問題，他說「他們之前自己不好好學，我現在才不要花 30 分鐘幫他們解決基礎問題。」
其實我有偷偷注意到~ 之前馬克都還算有耐心地幫普拉德大哥，但昨天普拉德大哥第二次去問他時，馬克直接回說「不好意思，我沒空!」我在前面偷聽到覺得超嗆的啦XDD 不過我覺得普拉德大哥其實也是滿敢的! 馬克那麼殺，雖然我跟馬克已經算是滿熟的，我通常也都不太敢問他問題，怕他覺得我怎麼會問這種笨問題 (我只敢問人超好的里奇大哥😆)，他居然敢狂問馬克基礎問題哈哈哈哈
因為我們這次做的
project 架構其實滿複雜的(而且會根據每個人的設計而不同)，所以雖然我知道要怎麼做我自己的 project，但如果有其他同學來問我問題 (除非他們的問題是 single
issue)，不然其實我都答不太上來，對於他們感到很抱歉，因為我真的沒有利害到那種程度T^T
例如有些人 routes
也設錯，controller
上的
methods 或 variable
沒 defined，然後也不知道要怎麼在 view
上寫 form
跟 pass
on the right instance variables，以上講的每個東西都息息相關，只要其中一個沒弄好，就跑不出來。我自己的做法是按照老師上課的筆記一步一步做，但我有些同學好像就是自己想到什麼就做什麼。
馬克說他是可以幫他們解決，但他做自己的project
時間都不夠了，才不要花時間幫他們，因為他覺得是這些人自己當初上課的時候不好好學加複習的結果，所以他一點也不會因為不幫他們而感到抱歉。我是覺得可能因為這些人有家庭或其他事情，所以沒辦法像我們一樣花這麼多時間在學習上。結果立刻被里奇大哥反嗆說「那他們當初可以選擇上 part-time啊 (既然選了 full-time
就要對自己負責吧)」 其實想想也是滿有道理的LOL
