2019-11-11

今天是雙十一 (雖然這個源自中國的購物節跟我一點關係也沒有哈哈)，但好友 C 說我們剛好在今天發表我們的 marketplace projct，會不會太湊巧😆
今天最值得高興的事，就是我的好友 T 的 PR 終於下了!!!!!!!!!!!!!! 真心是超級恭喜她的!!! 一路走來非常不容易😭 (等她到時候回來雪梨，一定要好好幫她慶祝一下😁)
今天十點開始發表，我差五分鐘就遲到了哈哈哈~  老師本來說要按照大家到教室的順序抽籤，結果前幾個同學抽完老師就把簽拿給我抽了(其實我是最晚到的一個，但我也沒多說什麼哈哈)，這次我一樣延續之前的好運，抽到 6 號 (我非常喜歡在前面報告，講完之後就輕鬆了)。不過這次的我根本完全沒準備，就上台隨便講講而已哈哈 (結果回家的路上里奇大哥突然把他的耳機拿給我說，「EC
你聽!」原來他偷錄了我跟馬克的 presentation!!!
幹嘛側錄別人啦，笑死我XDD)
感覺這次大家做的功能都比較類似，雖然主題是滿不一樣的啦，但基本上就是新增、修改、刪除和展示 (create,
edit, delete, show) 物品或服務，再加上其他相關功能，所以每個人上台報告時，台下同學發問的踴躍程度遠不如之前的兩個 projects
XD
俄羅斯同學妮娜的 project
是出租展示櫥窗，然後她示範她的作品示範到一半，我突然就看到 ‘Beauty
is Spirit’ 跟 ‘Aussie
Beauty Market’，想說「咦! 那不是我的 project
嗎?XDDD」沒想到妮娜會把我的作品放在她的網站上，超驚喜的XDD
但我同時也覺得很奇怪，因為我們兩個在這次的
project 期間完全沒說過一句話，她怎麼知道我的 project
叫這個的 (我這次做 project
時候非常專心，完全沒怎麼跟里奇大哥還有馬克之外的人聊天，就連偉恩大哥我也沒怎麼聊LOL)。
後來休息時間我特意跑過去跟妮娜聊天，她才跟我說因為她有在偷看我的 GitHub，然後她發現我在 GitHub 上的 user
stories 有寫到她的名字，她覺得我人很好居然有想到她，所以才決定在 presentation
舉例時用我的網站當例子 (但其實我當時把全班每個人的名字加老師、助教跟隔壁班的奈拉吉大哥的名字都用上了XD)。
里奇大哥的 project
是給寵物的 airbnb，然後他在示範時突然說「好~ 那我們現在來假設現在有一個使用者要預訂服務，讓我們來看看用誰好呢? 這裡有 Ed
Sheeran，不過我們這次不要選他….
選這個人好了!」然後他猛然把畫面往下一拉，立刻就看到我跟夯的合照出現在大螢幕上! 我當場整個人狂笑XDDDDDDD (大家不要這麼喜歡示範時把我放上去好嗎哈哈)
是說我一直以為我的資料庫結構圖還算簡單，結果中場休息時艾力克斯小弟跟我說「我一看到你的 ERD 時簡直要被嚇死了，也太複雜了吧!!!」我一開始還回說「有嗎? 我覺得很一般吧」但回頭一想，絕大部分的同學好像都只有四到五個表格，我居然有九個!!!
感覺真的是滿複雜的哈哈
總之我對於自己這個 project
的表現非常滿意! 感覺節奏控制得很好~ 雖然我每天都忙得昏天黑地，但感覺好像沒有前幾次那麼茫然了~ 功能感覺也做得滿完整的! 這次感覺同學的作品落差真的滿大的，很多人最後完成的作品大概是我做到第三天的程度(?)，感覺非常陽春囧
這次我最喜歡的還是里奇大哥的作品，我覺得他真心是全能型人才(不管是網頁設計跟資料庫結構都做得非常棒)，作品完整的程度我覺得完全是可以直接開始上線營業的那種!
馬克的網站結構一樣非常複雜(不過馬克的網站設計總是走極簡風，不是我的菜XD)，覺得他真的是非常厲害，可以在短時間就吸收上課的知識，然後就融會貫通的應用出來，甚至還可以指導同學(只是如果問他太多蠢問題，他會不爽而已XD)。
但像我就不行，我目前只能按照上課筆記複製老師講的功能，自己摸索然後做出一些其他功能而已，有時候還是似懂非懂哈哈 (不過至少不像有些同學連上課講過的功能都做不出來LOL)
