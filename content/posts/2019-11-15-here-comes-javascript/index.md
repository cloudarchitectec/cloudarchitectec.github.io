### 2019-11-12
Rails project 結束後，我們就正式開始學習鼎鼎大名的
JavaScript 了! 這幾天感覺沒什麼大爆點，但小小的笑點還是很多~
例如今天早上天使小哥突然提到，聽完我的報告後他很好奇化妝品到底有什麼，所以他回家看了一個介紹美妝的影片XDDD (天使小哥真心是一個超級奇妙的人LOL)
然後昨天雀爾喜姐姐沒來報告，我還以為她是生病了，沒想到她今天一來老師就說她昨天其實是去布里斯本校區報告了，大家都感到非常訝異!!! 我本來想說是不是因為雀爾喜的口條非常好(畢竟人家是前任雅思老師)，所以才被指派去另一個校區報告，結果後來跟她一聊才發現事情完全不是我想像的那樣LOL
雀爾喜說她男友是布里斯本人，他們剛好決定上週末回布里斯本度假，於是她就想說那她週一能不能直接在那邊的校區報告，這樣她就不用skype 視訊報告，結果人超好的助教就這樣幫她安排好了!!!!
我們學校感覺也太彈性了吧哈哈哈
今天早上上了 JavaScript
的 scoping
上的我頭昏腦脹，然後下午又連上了三個小時的離散數學，我整個上課上到好想死!!!
然後上到一半，凱西妹妹突然舉手發問說「請問為什麼0減負2會等於 2? (Why 0-(-2) = 2?)」我整個大傻眼XDDDD 然後助教還很認真解釋，全班同學感覺也沒什麼反應，只有我一個人內心波濤洶湧，想說你們澳洲人小時候沒學過這個嗎?XDD
