### 2019-11-14
一直到今天以前我都覺得自己對於 JavaScript 還算是游刃有餘，但中午跟同學聊天，艾利葉小哥也說「目前為止的
JavaScript 感覺都不太難，因為同樣的概念我們之前基本上都在Ruby學過了!
不過我有預感我們應該會一下子就突然加速到超難的地方~」 我立馬附和，因為我們之前學Ruby的時候就是這樣，前幾天都超簡單，然後突然一下子就開始變得超難!!!
但我沒想到原來今天就是這一天XDDD
今天下午的練習(馬克從昨天就開始做了，做了兩天還沒做完)，完全難到一個爆炸的地步!!! 我根本不知道要怎麼下手QAQ
途中我問了里奇大哥一個問題，然後我就開始看他是怎麼解，然後我們就一起完成了最後的步驟(當然所有的code都是里奇大哥寫的，我只是在旁邊出意見而已，而且我開始加入的時候他大概已經寫完80-90%了)，最後總共大概就花了 1-1.5小時解題(事後馬克跟我說他花了四個小時解出來)。我跟好心的里奇大哥要了一份他的答案，打算之後自己做一次，不知道要到底要花我多少時間LOL
今天下課之後我留下來參加我們 Bootcamp 辦的 meetup，是由我們的校友來講 progressive web application。其實後來聽了好幾個不同的人帶
lecture，真的發現我們目前的 bootcamp 老師還是當中最最會教的一個!!!
