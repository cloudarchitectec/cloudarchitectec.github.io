2019-11-18 & 2019-11-19

這幾天除了學 JavaScript
之外好像沒什麼爆點，總之我就像一隻蝸牛一樣慢慢爬慢慢學~
有時候老師講解了一些概念之後(當然老師都是舉簡化版的 coding
實例來教)，就會有同學問說「所以在現實生活中工程師都怎麼用這個 coding
概念(so
what’s the real world example for this code)?」然後老師就會開始舉實例，然後想當然耳，實例就沒有簡化版的 code 那麼簡單啊! 真心不懂這些人在想什麼，如果連「 1+1 等於 2」這個概念你都不懂，那現在我說「你先去超市買了一顆蘋果，隔天又再去超市買了一顆蘋果」這樣有比較簡單嗎?LOL
(這個例子舉得很爛我知道，但就只是我的小小抱怨哈哈)
這幾天去了好幾個 meetups，上週六去了一個整天的 JavaScript workshop，剛剛(週二晚上)又去了 11 月的 RORO，認識了一些新的人，突然有種人生也不過如此的感嘆。
例如有個越南女生是資深 C++工程師，而且至少會講四國語言(越南文、英文、日文、韓文)，她在韓國跟日本都做過工程師，結果現在到了澳洲已經九個月了，卻找不到工作!
因為 junior 的工作嫌她的資歷太資深，但 senior 的工作又說她之前的工作經驗 not relevant (我覺得她之前的工作經驗應該是比較像台積電工程師做晶圓的那種，介於軟體和硬體之間，澳洲 IT 業好像是純軟居多)，還有公司說她英文不好 (其實我覺得她的英文已經相當不錯了)。
然後今天去的
meetup 的講者是一個源自美國的 bootcamp 的老師，當初美國派他來雪梨拓展 Bootcamp
業務，結果現在他們在雪梨好像招不到學生，所以學校倒閉，他可能必須回美國了 (他好像才來雪梨六週)。從他的演講來說，我覺得他應該是個很好的老師。真心覺得世事無常~
最近藉由 meetup
參觀了幾個辦公室，覺得都好小好簡陋不夠氣派，位子都擠在一起，辦公空間感覺也不怎樣，跟 CA 相比落差超大的!!! 說真的 CA 的辦公室環境真心是近乎完美!!!!
