2019-11-25 to 2019-11-27
周一跟周二老師都沒來，雖然我們現在有兩個助教(舊助教漢堡還沒走，新助教布魯斯已經開始上班)，但兩個助教完全不知道要幹嘛哈哈哈哈~ 於是我們就廢了整整兩天😂不過也好啦，反正我們現在已經進行到了一個我完全什麼都聽不懂的階段XD
所以我就利用這兩天重看了一下老師之前的課程錄影，希望可以早日領悟，不然我現在練習題都完全不知道該如何下手……

週二下午我們去參觀了一家做建築安全軟體相關的公司(safety
culture)，不知道是因為知道老師不會來才突然排的行程，還是本來就有這個打算XD
在我目前去過的所有公司裡，這家公司的辦公室感覺算滿大的(共三層樓)，不過里奇大哥隊辦公室環境也不是很滿意(他果然是細節觀察家!
他甚至還注意到這間公司每層樓只有一間廁所哈哈)。其實我跟里奇大哥都有同樣的感覺，或許是因為我們之前都在大公司工作(里奇大哥的公司大概有1000人，CA大概200個)，所以我們都非常習慣有制度 corporate culture，對於比較 free style 小公司或是 startups 布置感到特別不能適應😂
其他我去過的公司感覺都好小，而且大家的座位都擠在一起(兩三個人擠一張桌子，然後所有桌子都挨在一起)，跟CA舒適的辦公環境相比真心落差很大(在CA我們一人有兩張大桌子、一個櫃子、兩個大螢幕加一台筆電)。讓我不禁開始思考我想要的
internship 公司是什麼樣子? 目前來說，我除了對大家的辦公環境不甚滿意之外，我對於他們的產品(建築安全、工作招聘網站、房地產、IT顧問業)其實也都不是很感興趣哈哈哈哈

週三老師終於來了，幫我們上了一點複習。馬克說「你不覺得複習完後概念又清楚了很多嗎?」我說「有嗎?????? 我不僅完全跟不上台上老師打code的速度，也聽不懂老師在講什麼哈哈哈」里奇大哥也因為完全搞不懂而很生氣XDD
連坐在後面的馬克都私下問我說「里奇今天又在不爽什麼?」我說「因為他懂了一部分但又沒辦法完全理解，所以才會對自己感到很生氣吧? 像我什麼都聽不懂，所以也氣不起來哈哈哈哈」事後里奇大哥跟我們說，他是因為覺得自己怎麼這麼笨，怎麼都聽不懂，所以很氣自己。他說「通常一般人的反應應該是會覺得很沮喪或氣餒吧? 但我跟別人不一樣，我是直接連跳兩級變成怒火!」結果馬克居然回說「嗯? 那不就是我嗎?」簡直要被這兩個隨時在氣噗噗的人笑死XDDD

週三也是我的lightning
talk (算是 public
speaking 的訓練?)
我講的主題是「你所不知道的台灣」XD
回響不錯，因為大家果然都被我帶來的旺旺仙貝跟雪餅收買(澳洲同學們普遍喜歡仙貝遠大於雪餅耶! 但我個人其實比較喜歡雪餅XD)
不過我還是需要更加強臨場節奏掌控，像是發完餅乾下去應該要等大家都拿到之後再開始演講，內容可能也還要加強~
因為我最後推薦了大家我最喜歡的五種珍奶口味，結果提問時艾利葉小哥居然問我說「所以珍奶到底是什麼?」我根本答不太出來，這種對我來說習以為常的東西也太難解釋了，我只好說「就是紅茶加牛奶加珍珠XD」
不過我對於身為澳洲人居然有人不知道珍奶是什麼我也是覺得很意外LOL(因為雪梨根本遍地是珍奶店?)
事後我問馬克說「所以你知道珍珠奶茶是什麼嗎?」馬克說「我當然知道啊! 我覺得會不知道的人應該是時代的關係吧 (I
think it’s a generation thing)，像我小時候珍奶店就沒現在這麼多~」馬克你在暗示什麼?XDDDD
但其實艾利葉小哥應該比馬克小幾歲耶~ 難道是區域差異? (因為艾莉葉小哥其實是
Perth 人~) 然後我覺得我的 lightning
talk 講完果然跟偉恩大哥開始小尷尬哈哈哈，雖然我已經避免談一些過於政治或過於有爭議性的話題XD


週三晚上也剛好是我們學校的聖誕節派對，必須說這真心是我參加過最不聖誕節的聖誕趴XD
首先辦在11月的周三晚上就已經夠奇怪的，整個學校也沒有多少聖誕節裝飾，也沒有 dress
code (大家都穿的黑壓壓一片，也沒帶什麼相關飾品)，甚至連音樂也不是播聖誕節相關的歌……
感覺我隨便一個朋友辦的聖誕趴都可以比這個有氣氛多了😆
不過這個 party
讓我覺得業界果然很小(看到很多我之前參加各式meetups見過的臉孔)，另外覺得我的social
技巧還是需加強(該怎麼自然加入對話跟順利地離開對話)!
在此特別感謝天使小哥，他人超好的啦!!! 只要看到我落單在旁邊，就會把我拉進對話圈然後幫忙把我介紹給大家!
另外這個party也有很多我們bootcamp的校友來!
甚至有一個我在bootcamp 開始前在
linkedin 找到的校友特地跑過來跟我打招呼(雖然我傳訊息給他，他三個月之後才回XD)!!!
說實話我一開始根本沒想起他是誰XDDD 因為我實在傳訊息給太多人了LOL (不過是個很帥的小哥XD)
最後我要提一下我最近的體悟「不要放大自己的煩惱，也不要放大自己的努力！」在這個課程之中，我常常覺得自己怎麼這麼笨，覺得課程真的好難。同時也覺得人生毫無意義，轉職到底是為了什麼? 我時常以為只有我自己有這個煩惱，但其實每個人多多少少都有這個困擾，所以不要每次一想到這件事情就很絕望XD 另外也不要覺得為什麼我這麼努力了，但還是學不會，那些不覺得緊張的人是不是已經放棄了? 其實不僅是別人的煩惱我們看不見，別人的努力我們其實也看不見! 所以我覺得 'worry
less, work more'，與其過度煩惱不知道該怎麼下手，不如直接開始動手做吧!
