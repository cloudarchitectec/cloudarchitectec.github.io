2019-12-13

今天不知道為什麼同學們上課都特別嗨，完全吵吵鬧鬧沒辦法靜下來聽老師上課(我一直到放學的路上才驚覺原來今天是週五! 我還以為今天是週四明天還要上課，難怪一堆人在說”have
a nice weekend”! 真心是遲鈍如我😂)
老師今天在課堂上宣布 final
project 會是 2-3 人一組….. 這樣人真的不會太少嗎?LOL
然後分組標準完全是老師自由心證，我直接舉手問他分組標準是什麼(是看個性合不合嗎?還是看 skills?)，結果老師居然給我一個「佛曰不可說」的回答 =_=
還說他有可能會特別安排兩個不熟的人一起，因為這就是 real
world project，你不可能永遠都跟你喜歡的人一起工作!😨
今天我們上了特別久的課，然後老師教到最後他自己的 code 也爆了，直接宣布下課，等他 debugging 之後，再把正確的 code
公佈到
github 上。我們今天學 automated
testing，我幫里奇大哥解決他的問題後就請他來幫我，結果我們兩個搞超久都看不出我的 code
有什麼問題，最後我把我的 code 傳給里奇大哥，結果在他的電腦跑就沒問題!!!
我去問了助教跟老師幾次都被打發回來，搞得我一把火!!!!!!!!!!!!!!!!!!!
因為我覺得他們根本就沒有要幫我看我的 code，最後老師直接跟我說不要管我的 code 了，把他的 code 複製下來跑就對了。結果我複製下來跑一樣 failed，但是在里奇大哥的電腦跑就沒問題(老師/助教/里奇大哥都是用 mac，我用 asus，難道這就是沒有用 mac 的差別?😭😭😭)。
我整個火大到不行又去找老師，老師一開始也不想管我，結果弄到最後發現 code 沒問題(當然我直接複製他寫的 code 啊)，但不知道為什麼我的電腦跑出來就是 failed，他才認真開始幫我 debugging (當然中間的態度都不是很好，所以我的態度也不是很好ㄎㄎ)，結果我們大概解了快一個小時也沒解出來，同學們都走光了，後來我就跟老師說算了，今天就到這裡吧! 因為老師晚上要去參加一個聖誕趴…
接著我去上廁所，看到好幾個女生 staff 在廁所濃妝打扮才發現，原來老師今天要去的聖誕趴居然是跟學校的人一起!!!!???
他們所有人打扮都超認真的啦，完全比上次辦給我們學生的還認真…..然後老師不知道是記錯還是說溜嘴，他們好像下週四還有一個聖誕趴(因為老師本來以為下週四那個趴是給學生的，結果我們說「可是我們已經辦過了啊」，才改口說是 staff 的???)
總之我今天非常不開心!!!
覺得他們這樣連看都不看就打發我真心是太鳥了，雖然我也覺得我要反省我自己的態度，因為我覺得我後來完全是把我不爽的心情擺在臉上(因為我就是氣炸啊XD) 但我決定看在老師後來還是幫我花時間研究的份上，原諒他吧~ (其實也沒有原諒啦! 反正我們本來就不合，"偶爾"維持表面和平而已啦XD
我們老師也是一個很情緒化的人，他要是心情好就會超嗨地跟我打招呼，要是心情一般就對我簡短回應，要是心情很差就當我空氣哈哈哈)
這裡又要再度稱讚里奇大哥真心是大大大好人~ 不僅花超多時間跟我一起研究(我其實跟他說了好幾次不用管我沒關係，但里奇大哥畢竟是一個很好奇心殺死貓的人😂)，甚至我最後一次氣沖沖殺去找老師的時候他就立馬跟在我後面，然後跟我一起待到五點半才走~
我回家之後不死心用跑了一樣同樣的程式….
結果這次完全沒問題，順利通過! 所以「重新開機」就是解決一切 IT 問題的關鍵嗎?😂 (其實在學校的時候我有重開機，但可見直接重啟是沒用的，要整個關機之後再開機才可以lol)
回家的火車上我跟里奇大哥閒聊說我昨天晚上都沒有做複習，因為我發現雷根小弟追蹤了我做的一個 Kahoot
記錄小程式(雷根小弟的 Kahoot 戰績大概是 90%，幾乎每次冠軍都是他，感覺他應該是真心很熱愛 Kahoot，所以才追蹤這個 project)。
我本來只是按照老師的要求隨便做了一個基本的小程式而已(因為老師跟助教好像又發現同學的學習狀況又不可控制了，現在很多人吃完午餐就走了，完全不做下午的練習，所以就強迫大家都要寫一個追蹤小程式，至少確保大家都有基本概念)，結果看到雷根小弟追蹤後，我昨晚就花了 2.5 小時把它升級成一個完整的程式😆
然後里奇大哥就立刻用一種詭異的表情看我，然後對我說「EC
你是不是喜歡雷根小弟啊?」我說「我沒有啊!!! 大人冤望啊~」然後里奇大哥就一直搶白我說「你要是真心喜歡他就說啊，我不會跟別人說的」(可是我真的沒有，請你冷靜!!!)。然後又說「嗯…… 雖然我支持你，但我覺得他可能不喜歡女生耶! 當然我還是支持你的啦，不過希望你之後不要太傷心….」(我真的沒有喜歡他，請你認真聽我說話LOL)然後就開始舉一些奇怪的例子，我一邊笑到內傷，一邊又想跟他澄清，但他又不聽我說😂
例如里奇大哥對我說「你通常都很早到，可是前幾天我看到你跟雷根小弟一起走進教室，那時候的時間已經比你平常到的時間晚很多了，但是你一點都不緊張~」(我只是因為在樓下咖啡店剛好遇到雷根小弟，所以就跟他一路聊天走上來而已。而且那天我其實是刻意晚到，因為我最近覺得早上提早到學校一點意義都沒有，教室很吵又不能專心，然後我現在坐第二排，現在大部分時間同學都沒有問題要問老師，所以老師就會無聊在講台附近晃來晃去，然後我就要跟他尷尬四目相對，仔細想想一點好處都沒有啊😆)。
然後里奇大哥說他的理論是因為雷根小弟每天都有花時間在打扮，還有在健身，然後還有他走路跟背包包的方式????
我個人對後面兩項是不予置評啦! 對我來說雷根小弟就是個時尚型男啊~ 我直接反嗆他說「那是因為你們這些男生 don’t
even try 吧(自己不好好穿衣打扮還怪別人😆)」
最後里奇大哥說「其實不只我一個人覺得你喜歡雷根小弟…」我當下直接在心裡吐槽說「對啊，另一個這樣覺得的人肯定是偉恩大哥啊，因為只有你們這兩個中年男子才會無聊到八卦我好嗎XDDDDD」
