今天我完全超晚到(約 10:15)! 完全以為大家應該已經在玩 kahoot!
了，結果一進教室發現完全沒有，問了馬克他說「老師 is

Day
80
今天是聖誕節前最後一天上課，不知道是不是因為這樣大家都特別晚來。然後我莫名贏了人生第三次 kahoot
XDDD (因為雷根小弟遲到了沒來得及參加，但即使這樣我還是贏馬克跟其他人啊顆顆顆) 事實上一直到第六題為止我都還在六七名徘徊，想說大家也都太厲害了吧!!
Kahoot 不只要比答對的題數，還要比答題速度(最後前三名都是 10 題全對，完全在比手速跟腦速啊XD)
一直到最後兩題我才衝到第二名，然後答完最後一題發現我第一之後我還有點不可置信，因為我選完就開始懷疑自己是不是選錯答案了XD
但總之可以再度贏得 Kahoot 還是非常開心~~~

今天同時也是公布我們最後一個大 project
的分組名單的日子，最後一刻完全緊張到不行，沒想到我居然跟俄羅斯妹子妮娜與俄澳混血羅比小弟一組，滿震驚的 (根本沒有設想過會是他們哈哈)!!!
最好笑的是，我早上在跟馬克講悄悄話，他問我說我最不想跟誰一組，我才說了是妮娜XDDD
(因為我週三跟她一起上 review，我發現她也是不太聽人講話的那種，我真心不太喜歡跟不太能溝通的人一組，結果立馬遭到現世報😆)
公布完組員名單之後每個小組要立刻討論出他們的隊名跟隊歌，我們的隊名是「俄羅斯大革命(Russian
Revolution)」，完全要笑死! 跟同學分享之後立刻被質疑說「EC
你又不是
Russians」，機智的我立刻回答「對啊! 他們是 Russians，我是 Revolution 啊XDD」 (其實這個隊名完全是我的主意，羅比小弟附議，妮娜不同意。我說沒關係，不然我們一人提一個名字，然後最後投票表決? 最後妮娜也提不出來，所以她就隨波逐流了XDD)
我跟里奇大哥一致認為馬克的 team 最棒! 馬克跟里奇大哥是唯一的兩人小組，其他每個組都是三個人。馬克的組員是一個個性溫和，但我覺得還算認真的人，感覺跟個性強勢的馬克會搭配得很好。里奇大哥的組員是艾力克斯小弟(他也是我最不想同組的人之一XD
因為艾力克斯小弟雖然平常聊天很有趣，但如果你跟他講解 code 他也是不聽人講話只想照自己的方式硬幹的那種，重點是他本人的 coding
實力又完全跟不上，超級悲劇…..)
不過回家的路上里奇大哥跟我說，他覺得我的 team 是全班最糟，因為我一邊要 babysit
羅比小弟(羅比小弟是個非常有趣的大漢，大概有 190-200 公分高，但是成績一直是班上的倒數)，一邊要跟頑固的妮娜抗衡。等於我一個人又要當 group
leader，又要當 project
manager，然後
coding 重責應該也是落在我身上 (然後妮娜可能還要在一旁堅持己見跟我對抗)，最後 presentation
應該也是我，因為羅比小弟從來沒有上台發表過他的 projects，一次也沒有，也沒有上台講他的 lightning talk (我猜測他應該是怕在全班面前丟臉? 總之他有嚴重的 presentation
心理障礙XD)，妮娜的 presentation
也不太行 (她在台上非常僵硬，而且妮娜口音滿重的，表達能力也不是很好，我其實平常偶爾跟她聊天都有一堆誤會😂)。
但我覺得里奇大哥的組更糟😆，因為他跟也是一樣非常頑固的艾力克斯小弟兩個人一組(至少跟頑固的妮娜有個資工學位，而且 coding 能力還算不錯)。總之看完全班的分組名單我覺得，我這組雖然不是最棒的(好想跟里奇大哥、馬克或雷根小弟一組喔哭哭)，但也不是最差的，因為還有其他好幾組我更不想在裡面哈哈哈哈 (這麼一想感覺老師的分組也不是沒有道理，至少我跟里奇大哥都覺得對方的組更糟XD)
我覺得老師的分組原則基本上就是把所有好朋友都拆散(幾乎所有人都是跟自己不熟，或是沒說過幾次話的同學一組)，然後試圖均衡每組的
coding 實力。就目前看來我們這組就是我扛(不過我其實滿慶幸妮娜的 coding 實力還不錯，只是她就是堅持己見難以溝通的那種😂，里奇大哥跟馬克那兩組當然也是他們兩個扛。偉恩大哥、天使小哥、麥克斯小弟一組，他們的 coding
麥克斯扛，然後 project
management 偉恩大哥扛。雷根小弟、路克跟凱西小姐一組，他們那組的 coding
是雷根小弟扛。剩下兩組幾乎沒有 coding 特別突出的人，不知道老師是怎麼分的XDDD (所以我其實也不想去剩下那兩組XDD)
總之之後會怎樣，就讓我們拭目以待吧哈哈
今天晚上睡前想說今天好像都沒怎麼 coding，於是就想說我來速速寫個 JavaScript challenge，結果我居然 11 分鐘就寫完了!!! 解出來的那一刻我自己根本不敢相信我居然在這麼短的時間就解出來了哈哈哈哈哈
