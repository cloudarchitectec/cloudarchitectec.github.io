### 2019-12-18
今天到了學校才發現我們今天一整天都要 review
JavaScript，因為老師想要確定在我們進入 react
之前大家都至少了解 JavaScript
的基本概念….
真心不懂他們這陣子趕課趕得要死，然後今天又完全停滯下來是怎麼回事!!!
早知如此，之前不要教得那麼快不就好了嗎? 更誇張的是，今天複習的內容居然是我們上學期倒數兩週的內容(也就是 11/15-11/30 的課程內容)…… 太棒了，事情都過了快一個月了你們才想要補救嗎? 不會太遲嗎?
老師跟助教一早先給了我們三個 mini
challenges，然後說如果沒辦法把前兩個做出來的人，建議去參加助教的 review
(比較基本)，想當然我要參加老師帶的 review
session 啊! (我的確也都有把前兩個做出來~)
結果老師上的 review
session 根本不是 review
吧，簡直難到我要哭出來!!!
午休時我就在跟馬克說我可能要換到助教那邊去了，下午回來還是那麼難，我就立刻站起來跟老師說「不好意思我要換過去助教那邊哈哈」。結果好笑的事，我一站起來，就有另外三個同學跟在我後面一起走了哈哈哈哈 (大家是否都在等我開第一槍?XD)
其實老師還滿過分的，因為他早上上到一半就說「如果你們發現這個 review 你們跟不上，你們就知道其實自己應該要在另一邊的」……
天知道他複習的內容跟早上給我們做的 mini
challenges 一點關係也沒有啊，而且講一個月前學的東西，誰會記得啊?
(雖然概念我有，但老師 review 的方式是給我們 instruction，然後要我們直接把程式寫出來，這算哪門子的 review
XDDD) 馬克說他沒聽到老師這樣說這句話啊，結果我旁邊的俄羅斯妹妮娜立刻附和她也有聽到，而且她也覺得老師是在暗示她XDD
(後來妮娜也跟我一起換去助教那邊了)
助教的 review
session 果然超簡單，立馬找回自信心……
然後我就發現他複習的東西我都知道，感覺也沒有學到新東西! 撐到五點助教還在繼續教(這點我倒是滿佩服助教的教學熱誠的)，我受不了就走了…. (雖然說更誇張的是，其實全班真的還有一半在苦苦掙扎助教幫我們複習的內容....)
所以今天花了一整天在學校，我知道的東西我還是知道，我不知道的東西我還是不知道! 大哭!!!!! 完完全全浪費我的時間，我還不如在家自習呢…..
然後我立馬想在四人小族群裡面大抱怨，但想想又覺得算了，反正我覺得我不管是參加哪個 session 我都不會開心的……
我最愛的抱怨小夥伴里奇大哥今天感覺心情比較好一點了，但好像也還是非常低潮，我也不想再添加他的負能量了。我還是在群組裡小提了一下這件事，但里奇大哥馬上就回說「我們結束的時候(老師的 review session 四點半就結束了)，我問老師能不能幫我們過一下早上的第三個 challenge，結果老師直接回我說那個不用管… 他從來就不會回答我的問題...」然後我也不好再說什麼呢，只能安慰他說可以明天早上問助教或找我跟馬克討論(我其實之前就寫過那題，馬克今天也有解出來)
