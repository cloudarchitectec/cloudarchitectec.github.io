2020-01-13

今天終於公布了 final
project 的評分標準，共分為兩階段。第一階段為期一週，必須準備技術文件，這次規定要寫的項目沒想像中多，但還是包含了幾個我們從來沒學過的概念XDDD
(這個 bootcamp
到底是怎麼回事? 怎麼老是要求我們在 assignment
的過程中自學新東西LOL)
第二階段約三週，是實際 coding 的部分，感覺 coding 的時間比想像中少，然後我已經開始擔心自己到時候會不會程式寫不出來了XDD
我們這組應該算是最早確定客戶的一組，也是老師最早 approved
project idea 的一組，直到現在都還有組別還在找客戶，想想都替他們擔心。不過目前聽到其他組好像都是要做類似賣產品的網站，這樣一響就覺得我們的 project
跟其他人還滿不一樣的XD
然後老師也突然宣布週三週四兩個整天要在學校進行 hackathon
(簡單來說就是把大家分成個個小組，在限定時間必須要做出一個成果來發表的活動)，組別會跟我們 project 的分組不一樣，讓我們練習
Git collaboration。因為老師覺得我們一組有三個人，完成所有文件應該只要兩三天，所以剩下的時間就可以拿來做這個活動。
今天是我們全天上課的最後一天(雖然我們還有兩個 topics 沒 cover，但老師說他會在之後視 project 進行的程度再教)。今天課程的內容連馬克都覺得難，里奇大哥已經覺得這幾天的課都莫名其妙到他都生氣了XDDD
(感覺里奇大哥再度進入
grumpy 階段哭哭~ 快還我很 mean 又很歡樂的里奇大哥!)
今天下午也是實習訓練第二步，其實講的絕大部分內容都是 common
sense。然後天使小哥不知道是這幾天嗑藥還是怎樣，一直狂問一些天馬行空又不相關的問題(他其實本來就這樣，不過在這兩天的實習階段裡特別誇張)，後來台上的墨兒只要看到天使小哥一舉手就開始皺眉加嘆氣。然後這個學校沒人控場的事件又來了，整個講座已經進行了整整一個半小時了，最後天使小哥還在那邊連續狂問了五個廢問題以上，我整個人一把火都上來了，直接對羅比小弟做了口型說”fuck 這個傢伙有完沒完啊”，搞到最後大家都超不耐煩的。後來教室後面有人受不了直接在天使小哥提問時把教室的燈打開(我們本來在投影所以教室的燈是關著的)，里奇大哥也是火到直接背了背包就走了~
中間小組開會的時候我與羅比小弟與妮娜展開激烈討論 (羅比小弟說我跟妮娜都快吵起來了，但我其實覺得還好XD)，今天唯一的壞消息是妮娜的兒子長水痘了，所以她明天不會來。我們五點多回家前分配完工作，然後大概六點多羅比小弟就秒速完成負責的部分了! 其實我對於我們這組的進度還是很滿意的，每個人手腳都超快XD
2020-01-14
今天我們有一整天可以討論我們的 project。雖然妮娜沒來，但她也是手腳非常俐落，早上八點多就傳其中她負責的一張圖表給我們，然後下午又傳了另一張! 我跟羅比小弟在早上大概把文件的部分寫完了(其實我覺得根本不用花這麼多時間在這裡，一切都只是在 BS 而已XDD)
然後我們下午四點也在白板上把所有的 wireframe
畫完了，感覺真心是累得要死，羅比小弟說累的程度簡直跟跑完一場馬拉松一樣XDD
不過等明天妮娜來我們還要再跟她討論，所以可能今天做的一切都會被推翻也不一定哈哈哈哈哈哈 (因為妮娜是非常堅持己見的人LOL)
羅比小弟跟老師還有助教的關係很好，所以每當我們需要問老師或助教問題的時候，我都叫他出馬! 羅比小弟還甚至在老師跟助教面前說「EC
很害怕問你們兩個問題，不知道為什麼」。其實我不害怕問助教問題，我只是覺得他很廢而已，講得答案都似是而非，根本沒什麼參考價值XDDD
(每次聽到他的答案我都只有翻白眼，但羅比小弟總是一副覺得很有道理的樣子! 我超想跟我的吐槽小夥伴里奇大哥吐槽的啦!!!)
至於老師的回答則是很有參考性，但是老師還情緒化啊，不如讓羅比小弟開頭然後我補充說明好了，至少老師回答的時後態度會好一點XD
下午公布明天 hackathon
分組名單時發現我跟里奇大哥還有湯姆一組，我當下就表現得很高興跟里奇大哥一組(當然啊! 里奇大哥這麼照，我們又是好朋友!)
然後我就聽到助教在後面跟老師說「你看吧? 她果然很高興!」 ….
如果我跟雷根小弟或是馬克一組我也會這麼高興啊哈哈哈哈
總之不管是老師助教或羅比小弟都對於本周的進度感到很樂觀….
我覺得他們真心只是好傻好天真! 雖然我們這組的進度算超前，但到時候真的用繪圖軟體把所有 wireframes
劃出來肯定會耗費比他們想像中更多的時間……..
但算了，擔心也沒用，就且戰且走吧!
