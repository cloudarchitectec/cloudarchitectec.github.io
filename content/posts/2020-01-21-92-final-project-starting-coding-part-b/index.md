2020-01-20
今天早上偉恩大哥要去我們的客戶的公司進行 internship
interview，然後下午我們跟客戶約了要討論project。在 reception
寫簽到簿時，看到了偉恩大哥的名字還有其他兩個 part-time bootcamp 的學生的名字，覺得我們的客戶也太忙了吧XDD
今天跟我們討論 project 的是客戶那邊的主工程師
(之前我們都是跟老闆談，我見過老闆三次四次，跟老闆比較熟悉)，會議進行的還滿順利的，加上前後大閒聊的時間也才一小時，我本來還以為會像上次一樣拖超久。
主工程師跟我們說，他跟老闆都對於學校居然沒有送我們三個(我、妮娜、羅比小弟)去他們公司進行 internship interview，感到很失望XD 希望我們可以回去跟實習負責人溝通一下，他們非常願意再多開面試場次給我們幾個…… (我私下問羅比小弟說「你覺得他是認真的嗎? 還是只是講場面話?」羅比小弟說他覺得主工程師是認真的) 恩，我其實很想跟他說「雖然你們沒有機會面試我(們)，但你們面試了我最好的朋友里奇大哥跟偉恩大哥啊XDDD (他們其實還面試了天使小哥跟另外兩個人，這樣還不夠嗎?
太貪心了吧XDDD)」
還有最後主工程師送我們出門時，他說「老闆對你們很有信心耶! 他覺得你們一定可以做完這個project，我個人是覺得在時限之內不太可能啦……」 哈哈哈哈~ 幹嘛這樣(大哭)
但羅比小弟的確也說，他說老師們私下也在說，我們這組做的project是最難的XDDD
2020-01-21
這兩天我們這組的寫 code 過程非常不順!
其實也不能說是我們這組，因為妮娜還是棒棒的，一個人就寫了好多 code，把我們的
server 最重要的元素都架好了! 還主動承擔了最困難的 feature。
拖累進度得其實就是我跟羅比小弟而已! 我們一起做第二困難的
feature (因為妮娜覺得我們應該從最難且最重要的做起，這樣就算到最後整個project做不完也沒關係，至少我們可以展現最關鍵的部分)，然後真心一路坑坑巴巴。
羅比小弟已經不只一次提過「其實我們不應該從最難的做起，應該從最簡單的做起，慢慢build
up」我其實不太同意，因為雖然我們現在做的是很難的 feature，但我跟羅比小弟其實連其中最簡單的component
(send a HTTP post request) 都搞不定啊哈哈哈哈哈
然後因為現在我們做的東西又息息相關，所以等於我跟羅比小弟要一起coding
(也就是一個人打字，一個人看，超級浪費時間的!) 而且我們兩個又幾乎什麼都不會(我本來以為我在班上是前段班呢，現在覺得我根本其實也沒比墊底的羅比小弟好多少吧XD)，就這樣兩個人一邊仿照網路上的tutorial，然後做到一半又卡住! 然後卡住的時候兩個人查資料也查不出所以然，總之很糟糕哈哈哈
唉~ 人生真的好難啊!
