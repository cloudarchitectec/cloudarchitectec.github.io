2020-01-15
因為今天要進行一整天的 hackathon
加上老師又要上兩個 topics
(deployment & git collaboration)，所以前一天就說我們今天要九點開始上課 (我們平常規定是九點到，十點開始上課，所以我後來都乾脆9:45才到XD)。因為太早起床，我一邊走一邊發呆，然後走一走就有個人突然從旁邊撞了我一下 (我持續發呆中)，結果後來才發現是里奇大哥故意在鬧我XDDD
真心是要被他笑死，他還問我說「你是不是覺得這個男的是變態，幹嘛走路走一走過來碰你一下?」 其實我真心沒有這麼覺得，我覺得只是不小心撞到而已哈哈
結果昨天才剛安慰里奇大哥要積極向上的我，今天就被自己打臉。一開始上課我本來跟得好好的，結果在最後15分鐘有一個小bug我弄不出來，所以後面就"棄了了"了。上完之後我立刻傳訊息給我旁邊的里奇大哥說「fxxk
my life! It’s so hard to stay positive!」 結果他狂笑XDD
11點我們正式開始 Hackathon 活動，這次的主題是做一個小app來提升工程師的心理健康。Wireframe 時我還多多少少能幫上一點忙，後來開始討論 coding
細節之後我就發現「完了，不管被分配到哪個部份我都不會做XDDD」 然後里奇大哥就開始問我說「你是不是生氣啦? 是不是對討論結果不開心?」其實我沒有，我只是突然 low
energy，然後就開始懶得用力氣做表情LOL
(這點真的很難治! 我真的沒有生氣!!! 我就只是心累了而已哈哈)
後來跟里奇大哥一起吃完午餐後我自己出去走走，回來之後就好了很多! 里奇大哥依然很罩，我們這組大概 90%的 code
都是他寫的，湯姆寫了 10%
(但是湯姆的 git
collab 概念跟 command
很強)，我大概寫了 0.001%
哈哈哈哈 (從頭到尾就是一個廢物😂)
最後15分鐘里奇大哥因為要去見他那一組 final
project 的客戶，所以要先走。我跟湯姆就速速把 code
合在一起(還遇到bug)，然後解決了這個小bug之後我們就回到教室準備上台發表了!
前兩組同學在發表時，我還在下面偷偷小改了一下格式，改完我直接就跟湯姆說，那下一組就直接換我們上吧?
(我一向是偏向早死早超生的那種，而且只有等我自己報告完，我才有心情欣賞其他同學的作品啊XD) 湯姆說好，然後我問湯姆說「你想上去講還是我講?
(其實我們兩個都沒準備XD)」，湯姆說「你可以講嗎?」然後我說好就上台了 (明明湯姆才是澳洲人啊哈哈) 因為完全沒有準備，所以我根本就上胡言亂語的一陣，事後偉恩大哥說「我發現你的口頭禪是 basically，因為你剛剛在上面一直講這個字😆」
