## 2026.10.02 Day 8｜布哈拉 → 撒馬爾罕

### 凌晨兩點的高鐵，抵達後直接開啟半夢半醒模式

{{< gallery cols="3" >}}
{{< figure src="images/bukhara-1.JPG" alt="夜晚亮燈的布哈拉火車站" >}}
{{< figure src="images/bukhara-2.JPG" alt="夜色中的布哈拉地標燈牌" >}}
{{< figure src="images/bukhara-3.JPG" alt="停靠月台的 Afrosiyob 高鐵" >}}
{{< /gallery >}}

烏茲別克的大眾運輸票真的滿難買的！網站很不穩定、結帳容易失敗，票也很少。朋友試了好多次，最後只買到凌晨兩點的高鐵票，我們四個人還分別被安排在兩個車廂。雖然買的是商務艙，座位還算舒適，但這個搭車時間實在有點悲劇。更奇怪的是，我們實際搭乘的時候，旁邊明明還有不少空位？

抵達撒馬爾罕時已經凌晨四點多，整個人睏到不行。還好民宿老闆有提供接送服務，省去了我們叫車的麻煩。

大約早上 5:30，我們抵達民宿放好行李，那時候大家都處於半夢半醒之間。我們訂了兩間雙人房，但只有其中一間有成功多訂一晚，而且已經打掃完成。本來想說要不要先在廚房躺一下，後來還是決定加入 Rita 的腳步，一起到附近的雷吉斯坦廣場（Registan Square）逛逛兼覓食。

### 清晨的雷吉斯坦廣場與「咻咻咻」音效

{{< gallery cols="3" >}}
{{< figure src="images/s-1.JPG" alt="清晨天空下的撒馬爾罕古建築與圓頂" >}}
{{< figure src="images/s-2.JPG" alt="黃昏時亮起燈光的撒馬爾罕地標招牌" >}}
{{< figure src="images/s-3.JPG" alt="烤爐旁一盤剛出爐的 Samosa" >}}
{{< /gallery >}}

不得不說，清晨來廣場真的不錯，人非常少！我們還遇到一位很有趣的印度人，幫我們拍影片的時候，他竟然自己用嘴巴配上「咻咻咻」的音效。因為實在太好笑了，從此之後，我們只要幫彼此拍影片，也都會忍不住發出同樣的聲音XDDD

簡單拍完照後，我們隨意走進附近一家賣 Samosa（烤包子）的小店。朋友一吃就覺得簡直是人間美味，但因為我還在生病，只能眼巴巴地看著，沒有吃到😭

在雷吉斯坦廣場附近晃了一圈後，我們回到民宿休息。因為我們的房間還沒準備好，於是我只好在公共區的躺椅上休息。此時 Rita 居然有精力還在旁邊工作，讓我非常佩服；至於我，則是直接睡死。

睡到中午醒來後，大家決定一起叫外送，接著才開始下午的撒馬爾罕探險。

### 山丘上的清真寺、市集與比比哈奴清真寺

{{< figure src="images/temple.JPG" alt="清真寺外牆上的藍色幾何磁磚與拱門" >}}

第一站是「哈茲拉提・希茲爾清真寺（Hazrat Khizr Mosque）」。清真寺位在山丘上，可以順便眺望城市景色。

{{< figure src="images/market-2.JPG" alt="市集水果攤上成堆的石榴與香蕉" >}}
{{< figure src="images/market-3.JPG" alt="有頂棚的市集通道與兩側攤位" >}}
{{< figure src="images/market-4.JPG" alt="市集攤位陳列的彩繪陶盤與人物擺飾" >}}
{{< /gallery >}}


接著走一小段路，就到了「Siyob Bozori（西約布市集）」。據說這裡是撒馬爾罕最大、最古老的傳統農貿市場。我的駱駝玩偶就是在這裡買的，超可愛！早知道當下應該多買幾個XDD 朋友們也在市集裡大逛一番，買到手軟。

{{< figure src="images/camel.JPG" alt="市集買來的駱駝玩偶掛在包包上" >}}

再來是「比比哈奴清真寺（Bibi-Xonim masjidi）」，據說是帖木兒大帝為了他寵愛的妻子比比哈奴而建。因為這幾天已經逛了太多清真寺，我們這次就只在外面拍照，沒有入內參觀。

### 沒等到燈光秀，卻預約了傳統服飾拍攝

吃完晚餐後，我們回到雷吉斯坦廣場，準備等待燈光秀。問 AI 得到的答案是燈光秀晚上八點開始，但等到 8:30 仍然沒有任何動靜。後來查看 Google Maps 的最新評論，才發現燈光秀可能是九點開始。

頂著第一天抵達的疲累，我們實在沒有力氣再等下去，立刻放棄，決定回民宿休息。

等待的過程中，我們也在討論隔天的行程。朋友想穿傳統服飾拍照，查了不少攻略都說要越早去越好，有些甚至建議預約清晨六、七點。但我們今天早上也是差不多那個時間到廣場，卻完全沒看到租衣服的攤販，讓我們很困惑，到底是要去哪裡租衣服跟找攝影師？

沒想到等燈光秀時，突然有一位攝影師主動上前搭訕。我原本對拍照行程沒什麼興趣，畢竟我個人其實沒有很愛拍照，但想想都來了，而且上次在韓國和媽媽一起穿傳統服飾拍照的體驗也不錯，於是決定加入朋友的行程。

同行四人中只有我們兩個想拍，最後預約了隔天清晨 6:30 的行程：兩人共用一位攝影師（本來說好要一人一個攝影師，攝影師也答應了，但其實只是話術，基本上不管幾個人都是一個攝影師拍。如果想要單獨拍攝，建議跟同行友人分開去找攝影師XD），拍攝一小時，每人 55 美元。

## 2026.10.03 Day 9｜撒馬爾罕：傳統服飾拍照日

### 清晨起床梳妝，準備變身撒馬爾罕公主

今天我們兩個大約五點就起床，還認真梳妝打扮了一番。因為拍攝行程只包含服裝租借和攝影，沒有妝髮服務。為了保險起見，我和朋友都在裡面穿了一身白（朋友是白衣白褲，我是連身白洋裝），這點非常重要！因為傳統服飾是套上去而已，穿其他顏色的衣物，都會很容易穿幫或是不協調，切記切記！

6:30 到達集合地點後，現場根本沒看到人。聯絡攝影師之後，他的夥伴才姍姍來遲，接著終於開始我們的拍照行程。

當時售票人員都還沒上班，攝影師直接把景點旁邊的護欄拉開，帶我們進去。原來他們的店就在廣場的古蹟建築裡面。

我們先把東西放進袋子裡，接著開始挑衣服。根據朋友前一天的觀察，紅色系拍起來應該比較亮眼，所以我一眼看中一套桃紅色服裝，完全沒有猶豫就決定是它了！朋友則選了另一套比較偏橘紅色的。

工作人員幫我們戴上簡易的飾品和頭巾後，就可以出去拍照了。

### 攝影師指導擺拍，奔跑公主影片拍起來

{{< figure src="images/dress.JPG" alt="穿著桃紅色傳統服飾的人站在撒馬爾罕古蹟前" >}}

後來我覺得，兩個人共用一位攝影師其實也不錯，因為拍照真的好累！我大概拍了前十分鐘，就已經累到不行🫠

攝影師顯然非常有經驗，整套流程相當熟練，會給我們很多姿勢和動作指示，也會同時用單眼相機和手機拍攝。我們兩個輪流上場，朋友拍的時候，我還可以在旁邊觀摩一下。

這次拍攝的重點之一，就是「奔跑公主」影片。攝影師會在不同地方指揮我們跑起來，讓裙擺隨著動作飄揚。成品真的滿驚人、也滿好看，很適合發在社群媒體上！

而且穿上這種誇張又美麗的傳統服飾之後，好像不管擺出什麼奇怪的姿勢都變得很正常XDDD

### 攝影師拍完，自己拍才是重頭戲？

拍攝結束後，攝影師直接把單眼相機和手機裡的照片、影片一次傳給我們，還滿方便的。

不過實際拍攝時間大約只有 50 分鐘，未滿一小時。朋友便詢問能不能讓我們繼續穿著服裝，自己再拍一下。稍微討價還價後，對方答應了，但要求我們不能離開指定的建築物。

接下來我們就開始自拍——主要是朋友在拍啦！我後來發現，自己拍其實能拍出比攝影師更滿意的照片！因為攝影師可能為了呈現完整的場景和飄揚的裙擺，常常把人拍得很遠，臉都看不太清楚。

最後我們甚至交換衣服，又拍了更多照片，玩得滿開心。直到工作人員發現我們怎麼一直還沒換衣服，我們才乖乖換回自己的衣服，準備繼續逛廣場。

拍完照之後，另外兩位朋友也睡醒了，我們便請他們幫忙買昨天吃的 Samosa 進來，讓我們可以在廣場裡吃。畢竟如果自己出去，再進來就要重新買景點門票。（是說我們拍完照後，攝影師突然說我們必須要把景點門票支付給他。雖然我覺得支付門票是合理的，但記得我們早上根本是直接闖入景點嗎？希望攝影師最後是真的有把景點給官方人員，而不是自己偷收起來🤣）

吃完 Samosa 後，我們又在景點裡稍微逛了一下。不過拍完照已經很累，加上這幾天也看過不少清真寺和古蹟，於是逛了一會兒就決定回民宿休息。

中午我們再度用 Yandex 叫外送。下午則前往一間古法造紙廠。

我們原本想找個不太一樣的景點，到了之後才發現，這裡是旅行團會帶團客來的地方，能逛的東西不算多。不過，我還是在這裡買了兩張很可愛的紙明信片～

後來我們又去了紅酒博物館，想說不然來個品酒行程。沒想到因為沒有事先預約，當天已經沒有名額，只能改天再來。

我們在路邊琢磨了一下接下來要去哪裡，最後決定回民宿附近，一起到一間有露台的餐廳休息，養精蓄銳，準備再次前往廣場看燈光秀。

這次我們晚上 8:30 才到廣場，現場已經人山人海。等了一會兒後，燈光秀終於在九點開始。

原本大家都坐在地上，但燈光秀一開始，就有觀眾按捺不住，想站起來拍影片。第一個站起來的人還被其他觀眾噓到坐下，但後來這股潮流實在擋不住，越來越多人站到了前面。

其中有一個人真的站在最中間，還轉過身來往後拍影片（他整場燈光秀都站在最中間，真的很惱人，非常影響觀賞體驗）。我當時非常後悔：早知道他往後拍的時候，我就應該對他比中指，讓他的影片裡留下我的中指XDDD

至於燈光秀本身，我覺得還好，個人覺得不看也可以。內容似乎是在講烏茲別克的歷史？但因為使用烏茲別克語，我也聽不懂；整體視覺效果讓我聯想到雪梨的 Vivid Sydney XD

還好民宿就在附近，走路十分鐘左右就能到，看完之後很快就能回去休息。

## 2026.10.04 Day 10｜撒馬爾罕：陵墓群與悠閒的一天

### 終於吃到現場出爐的 Samosa

這天我終於覺得自己好了一點，於是加入朋友去買 Samosa 當早餐的行程。朋友說現場吃和外帶吃還是很不一樣，讓我很期待～

沒想到今天的價格居然變貴了！這個 Samosa 居然還是實價嗎？我們連買三天，每天價格都不一樣🤣

吃完早餐後，我們前往「沙赫靜達陵墓群（Shah-i-Zinda）」。這裡真的有很多陵墓，走進一間間小房子，裡面都可以看到棺木。

我覺得這裡很適合拍照：景點集中，建築也很漂亮。不過缺點就是整個區域不大，所以遊客一多就顯得非常擁擠。我們吃完 Samosa 才去，大概八點多抵達時就已經有不少人，拍起照來沒有前幾天那麼順利。

拍完照一看時間，才早上九點。本來想說要不要去其他景點，但想來想去也沒有更好的主意，最後決定回民宿耍廢。

不得不說，民宿的躺椅真的很舒服！我們在那裡安排了一場早茶，拿出之前買的花果茶，還有在市集買的水果和果乾，我排出了一盤超漂亮的果盤。

午餐當然又是叫外送。整天的步調很輕鬆，畢竟玩到現在，大家也都有點疲倦了。

### 永恆之城與期待已久的韓式熱湯

{{< gallery cols="3" >}}
{{< figure src="images/city-1.JPG" alt="永恆之城店面前的傳統人物雕像與畫作" >}}

睡完午覺後，我們決定前往新景點「永恆之城（The Eternal City）」。

不過這裡可能還太新，感覺許多配套措施都還沒有做好。加上當天天氣不太好，似乎快下雨了，我們隨意逛了一下就決定回民宿。

到了這時候，我們已經有點受夠烏茲別克料理了，但附近的選擇似乎不多。加上天氣濕冷，大家特別想喝點熱湯。找來找去，終於發現住宿附近居然有一家韓式料理，讓我們非常期待！

因為我的身體還沒有完全恢復，所以直接排除烤肉這個選項。本來想點海鮮煎餅，結果沒有；想點蒸蛋，也沒有。最後我點了一碗排骨湯。湯其實滿鹹的，雖然肉很多、感覺很划算，但好像也不是特別健康，最後也沒吃完。

這時候 Rita 也開始身體不舒服，真的是給她一個大拍拍😭 我發現，身體不舒服的時候，跡象其實滿明顯的：首先食慾會下降，接著整個人也會開始有一種厭倦感。希望她可以早日康復～
