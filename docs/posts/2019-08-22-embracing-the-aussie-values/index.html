零基礎轉職澳洲工程師: 2019.08.22 Embracing the Aussie values? #

今天是平凡無奇的上課日XD 所以連一張照片也沒有哈哈 (通篇都是瑣事LOL)

教室位置大搬風 #

一到教室就發現蘇把她的裝備都移到最後一排 (我們本來都一起坐在第三排)，好奇的我走過去跟她打了招呼，她說因為她不喜歡一直坐著，移到最後一排可以隨時站起來活動比較方便!

同時，本來坐在第二排的偉恩大哥也移到最後一排，他說因為他之前的辦公室就是 「hot desking」，所以他喜歡四處移動XDD (hot desking 也就是沒有固定的辦公室座位，先到者先選位的模式。自從 covid 之後這種 hot desking 的辦公室文化在澳洲又更加盛行了，Amazon、微軟跟貝殼都是這樣，但是台灣好像還是固定坐位比較多? 其實我比較喜歡固定坐位，這樣可以在座位上擺自己的上班小物跟水壺，就不用常常在那邊拿來拿去)

眼見兩個我喜歡的人類都換位子了，選擇困難症的我也猶豫了一下要不要換……不過我覺得我滿喜歡坐在第三排的，所以就沒換!

結果完全是正確的選擇XDDD

我們本來是三個人共用兩張長桌，夾在中間的我腳常常卡到桌腳，現在蘇走了，我跟馬克等於一人霸占一整張長桌(我回家一想，我們應該是班上唯二兩個一人一張桌子的人，後面幾排好像是四五個人擠兩張桌子，好可憐LOL)，然後我也趁早上大家還沒來時去後面換了一把比較有背部支撐力的椅子，今天上課整個人爽歪歪XDDD (而且馬克比我聰明，我不會的地方他都會，也是滿罩的!)

社交就是我身為 I 人的壓力來源 #

午休時我為了躲避人潮，決定逆向操作，先去外面走一走，再回來微波午餐。沒想到不小心跟另一位埃及同學Emil (是說我覺得他的名字念有夠像email或emu 哈哈) 一起搭電梯，於是又只好被迫展開 small talk (哭)

Emil 同學是攝影師，他給我看了幾張他手機裡的作品，我覺得還滿厲害的! 之後回到學校吃飯的時候只小 social 了 3 分鐘，耶!!!

天使小哥笑點多 #

天使小哥超好笑的，我們不知道聊到什麼，他突然說「其實我不知道坐我旁邊的那個男生叫什麼」，我想都不想就直接說「他不是叫湯姆嗎?XDDDD」 (天使小哥，你有在跟你同桌講話嗎?XDDD 雖然湯姆真心也不是一個特別活躍的人，我也是今天老師點他問問題才知道他叫什麼! PS: 老師點他的時候，其實也沒記起他叫什麼LOL，然後Tom跟老師眼神交會後就自己說他叫Tom! 哈哈)。然後講一講天使小哥又說「喔~我本來要跟那個… 叫什麼啊? 傑克說…」 我說「我們班沒有人叫傑克! LOL」， 然後他又說了另一個名字，我們班還是沒有人叫那個名字啊!!!! 我真心要笑死了啦XDDDDD

學語言最有效的方式就是開口 #

沒想到放學時，我又不小心跟不知道從哪冒出來的天使小哥一起搭電梯，只好再度 social (哭)! 我才知道原來天使小哥的中文不錯，是因為他小時候在中國讀過幾年小學 (PS: 天使小哥再度與我展開中文對話)!

我問天使小哥去過中國那些地方，他問我說「你跟中國的城市熟嗎?」 我說「拜託，台灣人小時候都要學中國地理好嗎XD (雖然我不知道他有沒有聽懂哈哈)」 最後分開時天使小哥還跟我說「明天見~」，害我本來都已經要滑出口「see you tomorrow」，又硬生生轉為「明天見」XDD

我昨天回家也跟雀爾喜姐姐同路了一段，她也是英文講一講突然就開始「烙」中文，這些人真心是常常喜歡轉換語言，殺得我措手不及耶XDD

我覺得這個 bootcamp 對我來說完全也是英語訓練營! 我每天都要說超多英文(要social、要提問、要喇賽，還要解釋自己的想法)，然後現在完全也被傳染澳洲人不管在何時何地，只要看到「認識」的人就要展開small talks 的文化習慣XD

(未來的 EC: 雖然我是政大英文系畢業的，但以前的我英文口說其實滿糟的XD 因為我是一個很Ｉ的人，開口講英文時緊張到大結巴，發音也不是很確實！所以我在大學時英文系的口說課成績老是墊底，看到同學們開口時都是一口流暢的英文就超級羨慕的，這其實也是後來我為什麼決定要澳洲打工度假的原因。沒想到後來就在澳洲待了這麼久，現在一回想覺得自己進步滿大的，雖然我常常開口的時候也還是很緊張，但經過反覆練習，現在大概有90％的時間跟我對話的人看不出我很緊張? 果然每件事都是熟能生巧，就連假裝也是 XD)
