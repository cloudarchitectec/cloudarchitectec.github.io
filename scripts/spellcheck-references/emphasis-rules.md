# Chinese emphasis rules (EC blog)

Implemented by [`../check-spelling.py`](../check-spelling.py) — `apply_emphasis_hygiene()`.

---

## Policy

EC 中文正文是**口語敘事**，不是 Markdown 教學文或簡報。

| 做法 | 何時用 |
|------|--------|
| **不用強調** | 金額、倍數、年數、百分比、城市名、英文術語（`house`、`Brisbane`）— 讓數字自然出現在句裡 |
| **「」** | 真的需要標出語氣時：反問、比喻、引用口語、定義用語（**少而精**） |
| **`**bold**`** | **避免**在中文敘述句用 Markdown 粗體標單字；舊文政策文、連結標題除外 |

### 好／壞對照

| 壞 | 好 |
|----|-----|
| 在 **Brisbane** 要存 **12.9 年** | 在 Brisbane 要存 12.9 年 |
| 一間 **house** 的兩成頭期款 | 一間 house 的兩成頭期款 |
| **22.5 萬澳幣 (約 450 萬台幣)** | 22.5 萬澳幣 (約 450 萬台幣) |
| 改用**家庭收入**當基準 | 改用家庭收入當基準（或定義時寫「家庭收入」一次） |
| **要怎麼存出二十幾萬澳幣現金？** | 「要怎麼存出二十幾萬澳幣現金？」 |
| 連 **入場券（頭期款）** 都還在存 | 連「入場券（頭期款）」都還在存 |

## Auto-fix (spellcheck)

1. **Unwrap `**…**` → plain** — 含金額/數字/倍數/年/英文單字
2. **Convert `**…**` → 「…」** — 僅當：含 `？`、含括號比喻、或 ≥8 個中文字的完整語句
3. **Short CJK keyword bold**（如 `**家庭收入**`）→ 去掉粗體，**不**自動加「」
4. **Flag** — 處理後仍殘留的 `**`（需人工）

**Skip:** front matter、連結、code、已 mask 區域。
**Skip（2026-07-06）: 整行粗體** — `**…**` 佔滿一整行 = 刻意結構（Medium 偽標題或 pull
quote），auto-fix 與 flag 皆不處理。若確為段落標題，人工升級成 `###`。

---

## Writing (draft prose)

預設不加粗體。只有 rhetorical 口語才用「」，且一篇不超過數處。
